# 信息获取交互首版验证 · 2026-10-22

范围按用户确认收窄为融合版独立应用的可操作界面，真实采集后续实现。本页记录部署前的本地验收；之后已于 2026-10-23 发布客户生产环境，见[上线记录](../../deploy/parallel-test/releases/20261023-information-application.md)。

## 功能与边界

工作台新增「信息获取」卡片，沿门户会话验证身份与准入；`/information/*` 按需加载，不启动 PM 业务引导。
开发预览只有信息获取卡片可打开演示应用，PM / KB 的真实入口仍不在预览中跳转。
应用顶部显示实际登录身份；演示数据、计时、文件夹、版本、费用在模块内流转，不增加采集或入库接口。

包括七个页面；来源 Q/S/E/M、来源配置、批量收录向导、新建演示文件夹、暂停重试、逐文件原文与解析状态、
目录筛选、版本对照、问答示例、收件箱已读撤销与稍后看、关注笔记及可调费用假设均可操作。
费用仅为本地公式，不声称当前供应商价格或实际账单。

状态按验证后的 issuer / owner / subject 散列隔离；无隔离键与开发预览仅使用内存。
损坏的嵌套存储恢复为演示初始状态；刷新时暂停运行中的模拟任务，卸载清理计时器。

## 自动验证

- 前端：106 项测试、10 文件通过；账号模块原有逐文件 90% 覆盖率门槛保留，通过。
- 前端构建和门户路由检查通过；新增界面为独立按需加载分块，约 19.22 KiB gzip。
- 后端：300 项本地 SQLite 测试通过；原账号和门户分支覆盖率 93.77%，门槛 90% 保留。
- 后端格式检查通过；本次新增前端与测试文件的 ESLint 检查通过。门户已有 FastAPI `Depends` 的六项 Ruff B008 提示与基线一致，未改变规则。
- 后端全量测试的本机模拟 HTTP 服务须在允许 loopback 监听的环境执行；沙箱拒绝监听不作为服务功能失败。
- 新增测试覆盖无 PM / KB 角色仍可使用门户演示、异常身份被拒、命名空间稳定与账号隔离、损坏状态、原文模式重试、文件夹幂等及暂停恢复。
- 新路由集成测试以模拟门户身份验证实际姓名、返回工作台及不触发其他业务 API；不是实际 IAM 浏览器登录验收。
