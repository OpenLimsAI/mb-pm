# 参考资料 PDF 下载修复验证

日期：2026-11-06。基于 main `1512401b92360c0ae11935cb39337b0335e4cce8`，本记录描述本地代码验证，尚未合并或部署生产。

## 问题与修复

- 保存公开引用只保存来源链接；旧代码提前标记 PDF／参考论文，容易让用户把导入当成下载成功。现改为格式待核验、通用参考资料，收到 PDF 后才确认文件格式。
- 无公开 PDF 与网站禁止下载分别提示无法下载；保留原始链接，不自动收录 HTML 正文。
- 失败任务与逐文件原因默认展开，明确区分已处理、原件保存和失败数量；没有保存任何原件时不显示空的本批文件入口。
- 通过只读展示投影兼容历史任务与默认分类名称，保留自定义名称、分类 ID、文件夹和原件。历史失败判断读取全部相关任务，不受任务页最近 100 条限制。
- 区分永久不可下载与临时连接／指定 HTTP 错误；临时失败最多自动尝试三次。显式重试及成功后清理旧状态。解析、索引失败保留原件并复用后续流程。
- 当前版本的问答索引状态按当前版本 ID 或已核验摘要识别，避免其他历史版本的成功状态覆盖当前版本失败。
