# 本地工作应用整合提交

本次将当前统一工作副本的项目 AI、Agent 工作流、知识库联调、研究报告编辑和 Blue Edition 主题纳入同一条评审分支。基线为 GitHub `main` 的 `e781525`，同时保留此前六个本地整合提交的功能。本次没有发布生产环境。

## 范围

- 项目与任务范围识别、重点任务、排期比较、待确认提案、事件和后台 worker 生命周期。
- 工作台固定本地入口与知识库同源挂载、个人笔记来源校验、结构化模型输出兼容。
- 报告编辑工具栏、内联问答与 AI 差异审阅，以及全应用蓝色主题。
- 仅限本地 IAM 的主题工具、安全回读与回滚测试；独立蓝色设计稿及其源码。

工作台的应用目录与权限仍来自现有业务接口，未引入设计稿中的示例指标。私有运行配置、数据库、会话、令牌、构建缓存和归档旧副本不在提交范围内。

## 验证

- 前端 157 个测试文件、1,304 项测试通过；逐文件账号模块覆盖率门槛保持原值，覆盖率检查通过。本地限制两个并行 worker 以避免多个仓库同时验证造成资源争用，没有修改仓库测试超时或 CI 配置。
- 后端独立临时 SQLite：2,466 项通过、7 项跳过，账号/门户相关覆盖率 92.88%。这不替代 CI 的 PostgreSQL 回归。
- `ruff==0.7.0` 后端格式检查通过。
- 门户路由回归、生产构建保护回归、TypeScript 与前端构建通过。
- IAM 主题工具 12 项合成 HTTP 测试通过，未访问真实 IAM 或读取私密记录。

真实本地数据和账号继续由现有运行副本持有。完整的跨应用真实账号、Core 数据、模型调用和浅/深色视觉验收仍应作为发布前检查；本记录不将接口替身和页面构建称为真实业务验收。
