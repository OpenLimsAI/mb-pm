# 我的笔记

当前为本地预览功能，代码和隔离测试已实现，未推送或部署生产。

界面沿用研究报告的深蓝顶栏、浅灰工作区、浅蓝导航状态及「应用工作台」按钮。桌面左侧按全部笔记、个人记录、研究报告、行业信息和回收站浏览；窄屏改为顶部分类。右侧使用紧凑搜索工具栏与白色笔记卡片。编辑弹窗采用大标题、纸面正文、来源区和固定底部保存按钮，研究报告和行业信息中的笔记弹窗同步使用此样式。

- 入口：工作台 → 我的笔记（`/notes`）；本地预览 `/notes?preview=1`。行业信息侧栏也提供同一用户的笔记。
- 新建个人记录，或在研究报告正文、报告预览、AI 回答、行业资料详情与情报详情中选中文字，点击「存入我的笔记」。保存弹窗保留选区和来源，可在确认前编辑。
- 支持标题和正文搜索、个人/研究报告/行业信息来源筛选、编辑、移至回收站、撤销移除和恢复。不会永久删除笔记。正文按纯文本保存，最长 50,000 字，标题最长 200 字。
- 多页面编辑发生版本冲突时，保留当前弹窗内容，不覆盖服务器最新版本；创建重试使用同一 UUID。网络或浏览器存储失败也保留编辑内容。
- 正式接口使用门户身份，不要求论文知识库角色，也不调用论文服务。每人只可访问自己的笔记，IAM issuer 与账号共同构成所有权边界。来源仅为阅读线索，不自动作为报告证据。
- 演示笔记保存在本机浏览器的独立身份键中，刷新可恢复；不同设备和正式环境不共享。旧论文知识库笔记保持原样，不作自动迁移。

## API 和迁移

`GET /api/v1/notes` 按 search、source_app、trashed、offset 筛选，每页最多 50 条。`POST /notes` 创建；`PUT /notes/{id}` 编辑；`POST /notes/{id}/trash`、`POST /notes/{id}/restore` 软删除与恢复。创建请求包含 UUID，其他写操作包含 revision。写请求要求同源，过期门户会话返回 401，临时密码未改返回 403，版本冲突返回 409。

009 迁移仅新增 `personal_notes` 表和身份/更新时间索引，无 KB/报告外键。正式升级需备份并执行 Alembic 到 009。本次只在隔离 SQLite 测试升级、重复升级、结构与降级；未访问生产数据。
