# 备份分类、每日计划与删除管理

[返回功能说明](features.md) · [配置说明](configuration.md) · [主机适配器](../deploy/data-backup/README.md)

工作台业务管理下方为数据管理，进入数据备份。管理员可按分类查找文件、查看实际每日计划和健康提醒，并按需选择删除历史副本。每日备份继续使用现有脚本；安装支持计划编辑的同版宿主代理并显式启用后，可在页面调整执行时间或暂停、恢复该计划。代码实现不代表生产环境已部署。

## 分类与查找

点击「备份存储分布」中的分类卡片，下方只显示该分类的备份文件；支持返回全部分类、文件名称和内容搜索以及验证状态筛选。分类通过稳定目录标识关联，空分类明确提示没有备份。目录容量仍包含其他材料，不会把这些材料列为可删除备份。

改变筛选条件会取消原有勾选和删除确认，全选只作用于当前可见且允许删除的文件，最多100份。超过1000份归档时页面明确提示列表仅包含最近1000份，容量统计仍包含全部纳管文件，搜索及筛选只针对已加载列表。

## 每日计划

页面显示服务器确认的执行时区、每日时间、启用状态和预计下次执行时间。管理员可修改每日时间或暂停、恢复；时间按计划时区解释，记录时间按浏览器时区显示。备份期间可能短暂暂停业务写入，请选择业务空闲时段。保留规则仍由现有脚本负责，页面不修改其参数。夏令时切换附近的实际补跑／跳过行为由宿主Cron决定，预计时间不能代替实际完成记录。

宿主私有配置需设置 `allowPlanChanges: true`，旧配置默认只读。仅允许编辑准确识别的单条现有每日任务；缺少计划、未知时区、自定义周期、多个冲突任务或不支持编辑的旧代理均保持只读，并说明原因，不生成默认计划。保存使用计划修订号防止旧页面覆盖新配置，保留原命令、参数、环境、重定向和其他任务，读回实际cron后才显示成功；更改写入私有审计。人工直接修改crontab时需与页面管理串行操作；系统crontab命令不提供原子条件写入，写前检查不能覆盖所有外部写入竞争。暂停保留可恢复的原任务，不删除备份文件。

## 健康提醒

沿用现有监控标准，提示计划停用或无法确认、超过36小时没有新的完整已验证副本、完整归档无法读取以及磁盘剩余不足10GiB或使用达到85%。提醒用于排查，不会触发备份或自动删除。归档认证和清单核对通过不等于数据库恢复演练通过。

## 页面与数据来源

| 内容 | 来源和口径 |
| --- | --- |
| 备份计划 | 宿主机实际启用的已知cron及明确时区；无法确认或多份任务冲突时明确提示，不展示新代理默认计划 |
| 保留规则 | 当前执行脚本的可核对规则；未识别脚本显示待确认 |
| 每份备份 | 纳管目录中的真实普通归档文件，包含时间、文件大小、实际磁盘占用和来源分类 |
| 每份内容 | 历史归档认证、清单与摘要核对后生成业务名称；旧文件无可信清单时显示待确认，不按现有配置推断 |
| 目录和总占用 | 对明确纳管的备份根目录统计，目录展示文件逻辑总大小与实际总占盘，其他材料为其中的只读部分；归档总大小为逻辑大小；共享硬链接避免重复计算占盘 |
| 删除记录 | 服务端记录操作者、时间、数量、容量和最终结果；部分失败如实显示 |

列表不展示账号口令、连接字符串、原始配置、数据库记录或论文正文。系统管理员能看到公司备份记录；其他成员没有备份API权限。

## 选择删除

管理员可选择一份或多份备份，预览文件名、数量和容量，输入界面要求的确认文字后提交。预览令牌短期有效，绑定当前操作者及当时文件身份。文件已被替换、计划任务/发布占用锁、选择过期或账号改变时必须重新加载，不按旧页面静默删除。

删除只作用于指定纳管目录中的归档普通文件，不删除业务数据库、数据卷、文件夹或不认识的材料。最后一份已验证的完整可恢复备份受保护；尚未建立至少一份完整备份核对记录时不能开始删除。保护原因会在界面显示。删除不可撤销，成功及失败均写入私有审计；重复提交同一请求不重复执行。

自动保留由生产原脚本负责。页面的明确人工删除是独立操作，仍受最后副本和使用中保护；修改每日执行时间不会改变保留规则。

## 部署与验收

在最新main上提交PR，全部CI通过后squash合并，固定合并提交构建。安装同版本的宿主适配器和中继、私有配置和HMAC密钥，以仅后端可访问的私有地址提供服务；不得暴露公网路由。宿主入站受限时可使用私有Unix套接字与Docker私网中转；中转没有备份文件、解密密钥或Docker权限，原防火墙不变。后端配置 `DATA_BACKUP_AGENT_URL` 与 `DATA_BACKUP_AGENT_SECRET`。不挂载Docker socket，不替换备份执行脚本。启用计划编辑前保存原cron，并在合成环境验证修改、暂停、恢复和并发冲突。

上线前核对纳管根目录不重叠、真实文件权限、原cron与业务时区，保持旧备份与业务数据。历史归档初次扫描需要时间，扫描未完成时如实显示。先使用独立合成目录验证选择删除、最后副本保护、锁冲突及文件变化，再通过真实只读目录验收计划与容量。不要为了验收删除客户现有备份。

生产应用发布仅重建两个PM实例，完整保留其会话密钥、知识库连接、已有覆盖配置、安全设置、挂载和数据库结构；失败用固定旧镜像与原配置回滚。主机适配器停用不影响现有备份计划。

尚未接入页面的重要能力包括立即备份及任务进度、归档下载、恢复演练结果和异机备份／外部告警。立即备份需要处理业务维护窗口与防重复执行；现有隔离恢复脚本仍需运维单独运行。网页不恢复生产数据库。当前管理能力不能替代独立存储和恢复演练。
