# 知识源

知识源是知识库论文与文件夹管理器，入口 `/knowledge-sources`。它读取既有知识库论文及文件夹，按需从 ICH 下载公开 PDF 并归入来源文件夹。旧行业信息应用、旧管理接口和旧自动监控保持下线。新定期检查为独立设置，默认关闭；完整改进映射见 [28 项实现与验收](knowledge-sources-improvements.md)。

## 论文与文件夹

- 首页直接显示已有知识库论文，不用 ICH 目录中尚未下载的条目充当已保存论文。目录清单直接显示在来源页，不与已保存论文混在一起。
- 同一论文可属于多个文件夹，修改的是分类关系，不复制或移动 Core 原件。支持新建、重命名、批量放入、从当前文件夹移动和批量移除；从文件夹移除不删除论文。分类操作可按回执撤销，超过 500 篇时顺序分批并校验修订号，部分成功不会伪装成整批成功。
- Core 论文没有可确认的 PDF 原件时只提供原有知识库阅读入口，不宣称原件已下载或问答索引已完成。
- 已下载但尚未进入 Core 的 PDF 仍可阅读和分类。归档与知识库索引分开显示；解析、索引失败不删除原件。
- 已链接 Core 的论文被删除或不再可读后，不通过 PM 历史归档重新展示。新原文入口也实时核对关联 Core 论文可见性。
- 收藏按已验证发行方、组织和个人身份持久化，不改变团队文件夹。

首页文件夹管理面板包含全部主题和来源文件夹，支持搜索、类型筛选、清晰数量、空文件夹说明和独立重命名。勾选论文后可直接在目标卡片“放入此文件夹”，保留已有分类；移动仍是当前文件夹内的明确操作。首页“从来源下载”为突出主操作。面板可收起、个人置顶、按名称/数量排序，并显示上级路径。文件夹用途与来源默认目录分离，调整下载目标不改变“待整理”的判断。文件夹管理可设置用途/上级，删除仅移除分类；合并保留目标和论文原件。删除来源默认目录前须更换设置，合并会转移来源指向；有未结束任务的目录需先处理任务。

## 来源与下载

1. 在论文搜索源添加 HTTPS 官方网址和名称。ICH 复用原有来源，默认四类 Q/S/E/M；其他来源仅登记待适配，不执行通用网页抓取。
2. 默认接收文件夹使用来源同名文件夹；ICH 创建或复用 `ICH`。用户可明确指定现有文件夹。
3. 点击“再次搜索”，由后台逐类检查目录。结果直接更新到来源设置下方，不弹出预览窗口；搜索本身不下载 PDF。
4. 在页面内按标题、分类、资料类型、下载状态与 NEW/个人未查看组合筛选；“仅指南正文”使用官方资料类型，每页 25 份。“全选本页”只作用于本页；选择 Q/S/E/M 分类后，“全选本类”跨全部分页选中当前分类、关键词和下载状态下的文件，默认只选择未下载资料。切换分类会保留先前选择，共享资料不重复选择；可用“清空选择”重置。已选汇总显示唯一文件总数与分类数量，分类计数可重叠；“仅看已选”忽略上方筛选，集中核对所有选择。“取消本类选择”移除属于该类的已选文件，包括共享文件。可临时指定本次文件夹，不改变来源默认。选择是否建立问答索引后，点击“下载所选”才创建任务；失败保留选择，成功回执后清空。浏览状态按已验证身份与来源隔离恢复，失效文档 ID 不进入提交。
5. 后台逐份保存原文、提取正文并按选择提交知识库索引。离开页面不影响任务，运行记录保留逐项结果；可暂停、继续、取消剩余部分或仅重试失败项。任务按来源/日期/结果筛选，活跃任务置顶，历史默认折叠；逐项显示阶段，成功后可直接查看本批文件。已有原件的重试复用本地版本继续解析或索引，仅无原件时重下载。
6. 完成后打开目标文件夹整理；同内容复用既有原件和知识库入库回执。旧文件夹分类不会因重新下载而被覆盖。

NEW 表示最近一次成功搜索首次发现的逻辑文档。首次范围搜索建立存量基线，不把全部旧资料标 NEW；下次对应范围成功搜索会刷新标记，失败和未搜索范围保留原标记。既有文档 URL 或官方状态变化不冒充新论文。新增标记由服务端持久化，刷新页面不会伪造新增；只表示新发现，不表示未读、已保存或可问答。

同来源存在排队、运行或暂停任务时，清单仍可查看、筛选和预选，但不能重复启动搜索或提交下载；通过“查看当前任务”继续处理或取消剩余部分。

原文继续使用 `INFORMATION_DATA_DIR` 的受保护共享卷及 SHA256 内容寻址。大小、配额、公开 ICH 路径、robots、超时、速率、原文保护和扫描件限制沿用原实现，见[历史说明](information.md)。采集不调用生成式云端模型；选择知识库索引时使用已有嵌入配置。

## 版本、变化与研究衔接

“原件已保存”不等于最新版本。目录区分别显示未保存、版本待核对、核验时一致、有更新待下载；手动核验会下载官网 PDF 计算内容摘要，消耗流量但不保存新原件。官网同网址内容变化也可识别，已保存版本仍能从资料详情查看。官方撤回/替代状态突出提示；目录暂时缺失不推断为撤回。

NEW 的原有基线和成功搜索语义不变。个人“未查看”独立持久化，标记查看不改变其他账号或 NEW。更新页展示最近 100 条新增、官方信息及原件变化记录，详情可看前后内容；后台仍保留原事件。

详情“继续研究”可打开笔记草稿或选择可编辑研究报告，附带原文链接、原件版本及收录时间。用户确认才写入，报告校验修订号，未自动调用生成式模型。

## 用量与刷新

资源面板按当前组织的原件 SHA 去重统计文件数量和大小，展示已索引版本数及本版开始记录的 PDF 下载流量；核验流量也计入，历史流量不追溯。`modelCost`、`indexCost` 没有真实回执时为 `null`，界面显示未计量，不填写零费用。采集不调用生成式模型，索引沿用既有嵌入配置；摘要、翻译、AI 分类未自动启用。

运行任务约每 2.5 秒读取轻量状态接口，其他状态约 15 秒检查；任务变化后按需读取完整快照。论文列表每次增量展示 100 条，来源清单每页 25 份；当前仍保留首次全量快照，不宣称已经实现服务端论文分页。网络失败保留已有资料并显示加载时间，区分权限、限流、参数与冲突提示。最近下载可筛选今天/近 7 天/近 30 天，仅包含确认保存的原件。

## 身份与权限

所有 `/api/v1/knowledge-sources/*` 使用现有门户会话、强制改密和实时 IAM 身份。写入校验本站 Origin，不接收演示身份或浏览器 Core 令牌。

- 阅读完整 Core 文献库：实时 `kb_manager`、`kb_editor` 或 `kb_viewer`，由知识库桥接独立判断。
- 文件夹整理：实时 `kb_manager`，同时校验实际活跃论文、租户、版本及分类 revision。过期 revision 返回 409，前端刷新后重试。
- 来源配置与下载：沿用 `admin` 或 `kb_manager` 的公开 ICH 收录委托。单有 `admin` 不意味着获得全库阅读、通用上传、删除或模型设置权限。
- 对尚未链接 Core 的官方归档，保留原组织内的已验证阅读边界；归档分类待知识库创建后同步到同一份论文。

知识库不可连接或角色不允许时，界面显示实际连接问题，不加载示例论文替代真实结果。旧 `/information` 页面不因新应用上线而恢复。

## 配置和后台执行

| 配置 | 默认值 | 行为 |
|---|---|---|
| `KNOWLEDGE_SOURCE_APP_ENABLED` | `true` | 新应用和接口总开关 |
| `KNOWLEDGE_SOURCE_WORKER_ENABLED` | `false` | 知识源后台；生产启用时须显式设 `true`，来源定期计划仍须单独启用 |
| `INFORMATION_APP_ENABLED` | `false` | 旧行业信息保持下线 |
| `INFORMATION_KB_URL` / `INFORMATION_KB_SECRET` | 既有值 | 复用内网 HMAC 知识库桥接，不更换 Core 凭据 |

新线程 `knowledge-source-collector` 只执行带 `app=knowledge-sources` 标识的任务，使用原数据库 lease 协调两个 PM 实例；不运行、恢复或改写旧采集队列，不读取旧 `enabled` 作为执行依据。

新 `schedule` 默认 `off`。管理者可显式启用每日/每周检查，保存后下一次分别约 24 小时/7 天；仅检查读取目录并记录变化，不获取 PDF。开启自动下载后才依次检查目录、核验成功分类下的已有原件、下载新增或内容变化文件；索引需再单独勾选。关闭计划阻止后续自动阶段，历史原件保留。发布不会自动开启计划或下载全量 ICH。

API 包括 `snapshot`、`folders`、`folders/{id}/actions`、`papers/folders`、`papers/folders/undo`、`stars`、`sources`、`sources/{id}/check`、`sources/{id}/verify`、`changes/read`、`jobs`、`jobs/status`、`jobs/{id}/control`、`documents/{id}/retry` 和受保护原文。知识库服务新增签名 `library` 与 `folderMutation` 操作，保留原有收录/状态协议；需先发布兼容的 KB 服务再启用新 PM。

## 验证与交付边界

单元与 HTTP 回归使用隔离数据库、显式测试身份和可控 Core/ICH 响应，验证论文去重、文件夹多关联、归档原件、个人收藏、同源权限、删除屏障、任务暂停竞态和旧队列隔离。生产切换应额外记录固定源码、两个 PM 与 KB 镜像、数据库/分类/原件备份、只读核对及回滚目标；真实线上状态以发布回执为准。

## 界面规范

知识源沿用研究报告和我的笔记的深蓝应用顶栏、青蓝主操作、浅灰工作区与白色面板，统一字体、按钮、输入框、侧栏、卡片和弹窗间距。已保存论文和来源清单共用紧凑/标准密度，个人选择会保存；长标题保持可读换行。顶部复用 `ApplicationActions`，提供应用工作台、当前账号设置及共享主题切换。论文列表、来源设置和下载任务使用同一套样式；私有类名使用 `kso-*` 并限定在知识源容器内，避免研究报告懒加载后的 `.ks-*` 样式留存污染。门户知识区按研究报告、我的笔记、知识库、知识源排列。
