# 从研究报告和个人 AI 助手导入参考论文

本页描述代码实现；生产是否已启用，以对应发布回执为准。本功能需要门户与知识库桥接同时支持参考论文协议，不能仅发布前端。

## 操作

1. 在研究报告或个人 AI 助手的联网回答中，展开来源卡片，点击「导入知识源」。研究报告的侧栏问答、行内问答和选中文字问答均提供入口。
2. 核对论文标题、原始链接和分类后确认导入。研究报告归到「研究报告参考论文」，个人 AI 助手归到「个人AI助手参考论文」。导入保存公开来源信息，不自动下载，也不复制私人问题、回答正文或报告/任务标题到共享目录。
3. 有权限的账号可继续点击「下载原文」，或点击「查看知识源」在对应来源清单勾选下载。跳转在当前标签页完成，定位到该分类、论文或下载任务。
4. 下载任务继续使用知识源的原件保存、解析、知识库归档、问答索引及失败重试流程。来源卡片里的下载动作会建立问答索引；在知识源清单可选择只归档而不建索引。

「已导入」表示保存了标题和链接；「已保存原文」表示已有文件，解析或索引仍可能需要重试。重复导入同一分类下的相同规范化 URL 复用已有条目；已有活动任务不重复创建，已有原件在解析/索引重试时复用。两个来源分类可以分别收录同一论文，原件按内容摘要复用。

## 下载范围

支持公开 HTTPS PDF 直链，以及论文介绍页明确提供的 `citation_pdf_url`、PDF 类型链接或 `.pdf` 附件。只尝试有限个候选，不抓取整站，也不猜测论文地址。找不到公开 PDF、网站拒绝访问或下载失败时，保留导入信息与错误原因；不会把 HTML 页面当成 PDF 保存，不使用用户浏览器登录状态访问付费全文。

下载沿用原件配额与文件校验；参考论文另外限制单次读取总量 25 MiB、HTML 2 MiB、最多 4 次重定向和 3 个 PDF 候选。每次请求和跳转均校验公网 HTTPS 地址、固定已验证 DNS 地址并核对 TLS 主机名，遵守来源 robots 规则，不转发会话、模型密钥或代理凭据。

## 身份与接口

- `POST /api/v1/knowledge-sources/references` 接收 `originApp`（`solutions` 或 `assistant`）、`originId`、`answerId`、`referenceId` 和 `download`。后端从当前登录账号和发行方所属的已保存回答读取真实来源，拒绝前端传入任意 URL 或标题。已删除报告、任务或对话不能作为导入来源。
- 普通已登录账号可导入本人回答中的公开来源信息；下载和创建分类文件夹仍需知识源负责人权限及知识库写入权限，后台执行时再次核验。分类文件夹首次下载时创建或复用。
- 返回 `sourceId`、`documentId`、可空的 `folderId`、`category`、`alreadyImported`、`canDownload`、`status`（`imported`、`queued` 或 `saved`）和可选 `jobId`。
- 门户向知识库发送签名导入请求时，仅参考论文使用 `sourceKind: reference`。知识库独立核验调用身份、写权限、文件夹、PDF 标记与摘要；未声明该类型的旧 ICH 协议仍保留原域名/路径限制。
- 不新增数据库表、迁移或外部服务密钥。参考论文使用现有知识源记录、任务和受保护原件卷；不启用定时搜索或自动下载。

界面预览仅演示入口、分类与确认过程，不保存到真实服务端或发起下载。

## 研究现场提示

报告正常返回时静默恢复章节、主题和资料选择，不因存在浏览记录就提示「已恢复」。恢复未发送的问题时短暂提示 5 秒，提示消失不会清空问题；恢复未保存正文或中断提问时保留需要处理的提示。未保存正文提示优先，不会被普通研究现场提示覆盖。

## 验证

前端覆盖导入确认、两类来源、权限、重复导入、失败重试、同页定位、嵌套弹窗焦点和恢复提示。后端使用隔离数据和受控网络响应验证本人来源、跨账号/发行方隔离、同源写入、下载权限、任务复用、地址校验、公开 PDF 发现和失败保留；知识库桥接独立验证新旧协议边界。测试不调用外部模型或下载真实论文。
