# 知识源简洁界面

- 滚动页面时，标题栏与“资料库 / 来源下载 / 自动导入 / 下载记录”固定在窗口顶部。文件夹栏只在资料库展示，其他页面使用独立内容区。
- 资料库默认保留搜索、筛选、上传 PDF 与紧凑列表。点击资料标题后才打开阅读面板；“上传 PDF”进入独立操作区，返回后继续浏览原分类，不在列表上方插入大型表单。
- 资料搜索提示当前文件夹范围。已生效筛选可单独清除，重置筛选会恢复默认搜索范围。文件夹无匹配项时可保留关键词，切换到全部资料搜索。
- 文件夹旁的“⋯”可重命名、删除和打开更多设置；删除只移除分类关系，保留论文和原件。来源默认文件夹或有未结束任务时先处理关联。
- 每行右侧显示“调整文件”。点击按钮或勾选复选框可选中文件，也可跨页选择。资料列表上方直接显示拷贝、移动、移出、删除、共享标签及导出控件，选中文件时原位启用。拷贝和移动先选择目标文件夹，再确认。
- 添加资料仅保留 PDF 上传，每批最多 10 份，每份不超过 25 MB。文件逐项校验，保留同一批中的合规 PDF，并列出未加入的文件及原因。上传前读取文件，错误时保留待处理文件，支持取消。从具体文件夹打开时默认保存到该文件夹；其他入口默认“待整理”，不创建手动收录分类。ICH 官网下载继续归入 ICH 或明确选择的下载文件夹。
- “待整理”是系统创建的真实文件夹，固定显示在文件夹列表顶部，不重复显示为快捷筛选。未指定目标的手动上传存入此文件夹；拷贝或移动到其他文件夹后移出待整理，移除最后一个分类后回到待整理。旧的待整理链接继续可用。
- “移出此文件夹”只在可写的普通文件夹中启用，移出后仍可在知识库找到原件。“删除”会显示文件标题和受影响的可见文件夹。若选中多份，逐份确认，可随时退出，尚未确认的文件仍保持选中。
- 文件夹栏与资料区之间的分隔线支持拖动、方向键调整和双击恢复，宽度按当前账号记忆；窄屏隐藏拖动线。
- 来源清单直接展示，保留 Q/S/E/M、全选本类、再次搜索、NEW 和下载进度。来源概况明确显示保存位置、当前更新方式和最近搜索；“来源与自动下载设置”默认收起。选择汇总位于清单后，不因勾选向下推动文件列表。
- 在文件夹标题旁打开“自动导入设置”，侧面板只显示保存到此文件夹的任务。尚无任务时直接进入新建流程，预选当前文件夹。任务可查看扫描目录、计划和上次结果。
- 窄屏仍在一行显示四个主入口，资料库可点击当前文件夹名称旁的“切换”打开分类列表。文件操作栏随宽度换行，选中或取消时列表位置保持稳定。

业务入口为 `/knowledge-sources`。本地可在 `http://localhost:1234/scripts/fixtures/folder-imports/index.html` 使用合成资料验收。

待整理及知识库删除依赖门户和独立知识库配套服务。待整理上线记录见 [2026-11-17 发布回执](../deploy/parallel-test/releases/20261117-knowledge-source-inbox.md)。百度网盘分享目录下载仍不支持。
