# 知识源简洁界面

- 默认工作区保留文件夹、搜索、筛选、添加资料与紧凑列表。点击资料标题后才打开阅读面板。
- 文件夹旁的“⋯”可重命名、删除和打开更多设置；删除只移除分类关系，保留论文和原件。来源默认文件夹或有未结束任务时先处理关联。
- 全选本页、数量与批量操作共用固定高度工具栏；勾选和取消不改变论文位置与滚动位置。放入文件夹、移动、共享标签和导出从浮层完成。
- 默认 PDF 上传，保留每批 10 份、单份 25 MB 限制；上传前读取文件，错误时保留待处理文件，支持取消。
- 来源清单直接展示，保留 Q/S/E/M、全选本类、再次搜索、NEW 和下载进度。低频设置与额外筛选按需展开。
- 窄屏提供文件夹入口，批量操作浮层不推动列表。

本次仅修改门户前端与文档，现有接口、数据库和知识库服务不变。百度网盘分享目录下载尚不支持，未列入本次范围。已于 2026-11-16 部署，验证与回滚版本见[发布回执](../deploy/parallel-test/releases/20261116-knowledge-source-simple.md)。真实用户业务写入未代替用户验收。
