# 知识源简洁界面

- 默认工作区保留文件夹、搜索、筛选、添加资料与紧凑列表。点击资料标题后才打开阅读面板。
- 文件夹旁的“⋯”可重命名、删除和打开更多设置；删除只移除分类关系，保留论文和原件。来源默认文件夹或有未结束任务时先处理关联。
- 全选本页、数量与批量操作共用固定高度工具栏；勾选和取消不改变论文位置与滚动位置。“拷贝到文件夹”保留已有分类，“移动到文件夹”移除当前分类；整理与更多操作浮层互斥。不再显示撤销整理横栏。
- 添加资料仅保留 PDF 上传，保留每批 10 份、单份 25 MB 限制；上传前读取文件，错误时保留待处理文件，支持取消。从具体文件夹打开时默认保存到该文件夹；其他入口默认“待整理”，不创建手动收录分类。ICH 官网下载继续归入 ICH 或明确选择的下载文件夹。
- “待整理”是系统创建的真实文件夹，固定显示在文件夹列表顶部，不重复显示为快捷筛选。未指定目标的手动上传存入此文件夹；拷贝或移动到其他文件夹后移出待整理，移除最后一个分类后回到待整理。旧的待整理链接继续可用。
- 文件行垃圾桶可发起全知识库删除，确认框先检查影响范围并记录删除进度；未登记的服务器原件尚不支持全库删除，显示原因。只需移除分类时使用“从当前文件夹移除”。
- 文件夹栏与资料区之间的分隔线支持拖动、方向键调整和双击恢复，宽度按当前账号记忆；窄屏隐藏拖动线。
- 来源清单直接展示，保留 Q/S/E/M、全选本类、再次搜索、NEW 和下载进度。低频设置与额外筛选按需展开。
- 窄屏提供文件夹入口，批量操作浮层不推动列表。

本地版本同时修改门户与独立知识库接口及分类存储，需一并运行才能验证上传、系统文件夹与全库删除。百度网盘分享目录下载尚不支持，未列入本次范围。历史简洁版发布见 [2026-11-16 回执](../deploy/parallel-test/releases/20261116-knowledge-source-simple.md)。本轮待整理与文件操作改动需门户和知识库同时发布，部署回执另补。
