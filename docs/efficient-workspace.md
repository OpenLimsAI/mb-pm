2026-11-02 按已选定的「高效工作台」布局和「极光青」色系实施。本文件说明代码行为；生产是否发布以部署记录为准。

## 统一规范

- 白色 56px 应用顶栏，轻灰工作区和导航；主色 `#087A86`、强调文字 `#08616C`、正文 `#18373E`、次级文字 `#5B747A`、边框 `#D7E4E6`。
- 常规界面正文 14px，业务应用原有 9–11px 辅助文字提升为 12px；主要数据与阅读正文保留相应层级。
- 按钮 6px、内容区 6–8px 圆角，减少大面积深色、装饰渐变、阴影及重复卡片层级。
- 公用颜色定义在 `src/styles/efficient-workspace.css`；Tailwind 品牌与文字 token 在 `tailwind.config.js` 中使用相同色系。业务样式引用公用变量，按需加载后仍遵循共同外壳。

## 页面行为

- 门户：桌面导航固定在左侧，欢迎区域收紧，应用按原版块以紧凑入口排列。既有准入、未开通说明、预览限制和锚点导航保留。
- 项目（2026-11-03 更新）：分为「全部项目」和「工作台」，首次默认卡片直达项目；工作台聚合跨项目行动事项，取消先选项目再开详情的步骤。完整口径见[功能说明](features.md#项目入口与行动工作台2026-11-03)。
- 首页：组合指标压缩高度，风险信息提前；角色分流与统计口径不变。
- AI 助手、研究报告、笔记、知识源：统一顶栏、账户区、返回入口、按钮和信息密度，保留各应用的分栏、阅读、写作及问答交互。
- 知识库为独立仓库，本仓库只定义门户入口；知识库对应变更需由其自身构建交付。
- 本次不改变身份、权限、接口、模型调用、数据模型或持久化逻辑。既有明暗切换保留。

## 验收

本地 UI 预览使用 `VITE_USE_API=false npm run dev -- --host 127.0.0.1 --port 5210 --strictPort`，入口为 `http://127.0.0.1:5210/?preview=1`。该模式不连接客户数据库，不代表真实 IAM/SSO 验收。

检查门户锚点与应用跳转、项目直达、返回恢复及任务保存后的汇总一致性、真实内容空态、原有业务入口、窄屏布局、键盘焦点和深色切换。构建及回归通过后，按仓库 PR → CI → squash merge 流程交付；未记录发布前不要认定生产已升级。
