# AI 助手

AI 助手已部署生产。本次六项 DIKW 只读工具与知识库连接的发布、实际 Core 验收和待验收范围见 [2026-10-31 发布记录](../deploy/parallel-test/releases/20261031-assistant-dikw-tools.md)。

## 入口与工作界面

应用工作台最前面的「AI 智能版块」提供 AI 助手入口。独立地址为 `/assistant`，本地界面预览为 `/assistant?preview=1`。界面采用系统深蓝顶栏、浅蓝导航与白色工作区。

- 顶部工具栏：应用工作台、当前登录账号与主题切换。
- 左侧导航：新建任务、数据设置、AI 模型设置、回收站和任务搜索；每条任务旁直接提供删除，回收站任务旁提供恢复。
- 中间对话：按“提问＋回答”分轮展示，独立卡片标明轮次和消息时间；提问区使用加深的蓝色底和深色文字，与白底回答区形成明显区分；长回答之间保留明确边界。附带资料保留在对应提问下，复制和查看产物保留在对应回答下。
- 右侧结果：在概览与产物之间切换，查看任务指引及独立回答，复制或导出 Markdown；支持收起和放大。

桌面并列显示三栏；较窄窗口将结果改为侧边抽屉，手机上任务导航也可展开和收起；任务加载失败时自动展开导航，错误提示中也可直接返回任务列表。

## 使用流程

1. 新建任务，填写名称，可选填任务指引。
2. 在「数据设置」中选择是否使用知识库，知识库模式只读取所选应用的数据；自动模式按问题决定是否需要读取，不选择时不读取应用数据。设置保存在当前浏览器，按用户和预览环境区分。
3. 输入本轮目标，按 Enter 发送，Shift + Enter 换行。
4. 可在任务资料中导入 Word（`.docx`）、PDF、Markdown，或粘贴正文。导入沿用研究报告的本机解析器，不上传原始文件；发送时只带弹窗内确认的正文。单文件最多20MB，本轮参考正文最多20,000字，超限需截取后再使用。扫描PDF需先OCR。
5. 选择企业默认模型或自己的个人模型，发送问题。每项任务保存独立历史，每轮回答形成一份可查看、复制和导出的 Markdown 产物。
6. 可以切换任务继续工作。迟到的回答只更新原任务，其他任务的输入草稿保留。问题失败时保留当前输入，重试复用请求标识；有版本冲突时先刷新核对。
7. 任务设置支持更名和指引修改。在左侧任务列表点击任务旁的删除按钮并确认，即可移至回收站；无需先打开任务，对话加载失败时也可操作。回收站列表同样可直接恢复，对话和产物保留。删除/恢复只管理本人任务的状态，不返回受限的历史内容。

问题最多12,000字，任务名称最多200字，任务指引最多4,000字。正式接口每项任务最多100轮，模型最多带最近3轮的问题节选；选择应用数据或历史包含应用数据时，不带历史回答或资料，以免沿用已取消选择或已失权的数据。未选择应用且近期历史均未使用应用数据时，带历史回答节选。导入资料、用户指引和历史均为上下文，不作为已验证证据。

## 回答来源与正文

每轮回答上方显示实际采用的方式及来源。通用回答标明“未查询知识库 · 未联网”；仅允许某个数据源，并不表示本轮已经读取。历史记录缺少方式或来源信息时不补充检索状态，不把旧回答推断为通用回答。联网引用和应用数据范围继续依据本轮保存的来源显示，预览始终标为演示。

正文直接给出结果与必要解释，不主动罗列未启用的工具、空资料字段或后台变量。确实缺少回答所需的实验数据、证据不足或用户询问来源时，仍用普通语言说明具体限制；知识库权限、连接、超时和输出超限等真实错误继续在错误区域提示。不会通过删改模型正文隐藏限制，也不批量重写已有回答或产物。本次改动用于后续生成的回答。

## 模型与数据边界

个人模型配置与工作台 AI 设置、研究报告共用；密钥由后端加密保管，浏览器只接收是否已设置标记。选择「企业默认模型」可显式使用企业配置，不因返回设置页而被个人默认选择覆盖。普通助手不提供「仅检索资料」选项。

正式任务使用门户 Cookie 身份，按 IAM issuer/sub 隔离，不要求 PM 或知识库角色。预览使用独立的 `mberp:assistant:preview:v1:<namespace:user>` 浏览器键，带入门示例，刷新可恢复。本地预览不调用真实模型、不接收真实密钥，其回答明确标注为流程演示。

选中知识库后，沿用知识报告的实时 KB 权限和连接配置，先读取有效论文总数，再由当前模型按需调用 DIKW 只读查询工具，检索段落、读取原文和追查关联页面。超限会标记资料不完整，权限或连接不可用时返回错误。用户主动附加的本轮资料仍会发送给模型。预览不读取真实应用数据。既有生产工具不执行联网搜索、邮件、定时调度或业务数据修改；本轮新增公开检索适配仍处于开发预览，默认未启用，见[自动问答与联网搜索](assistant-auto-search.md)。

## 接口与升级

`/api/v1/assistant/tasks` 提供列表、创建、读取和修改；`/{id}/messages` 发送问题，`/{id}/trash` 与 `/{id}/restore` 软删除和恢复。这两个接口仅按归属和 revision 原子修改任务状态并返回任务摘要，不加载或返回消息、上下文和产物；详情、修改指引、问答及重放继续执行原历史范围检查，恢复不等于获得历史阅读权限。创建采用 UUID，修改和提问使用 revision，提问另带 request_id。完成后的同内容重试直接返回保存结果；并发模型生成只保证不会重复保存消息，不承诺外部推理恰好执行一次。

010 迁移新增 `assistant_tasks` 与 `assistant_messages`、归属索引、消息顺序和请求唯一约束。模型等待前释放读事务，返回后重新校验归属、任务状态和版本，再原子保存一对问答。012 迁移为消息记录增加数据范围，用于重试校验；正式运行需先备份并迁移至 012；现有生产已使用该结构。本次工具接入无新增迁移。

## DIKW 查询工具复用（本次更新）

工具合同核对自 [dikw-web b415100 的 Agent 注册](https://github.com/OpenDIKW/dikw-web/blob/b4151002d838b7fd22920a0adacbd7c3c797a9af/packages/web-server/src/agent/adkTools.ts)。它们是通过 HTTP 访问 Core 的函数工具，不是 shell/CLI。Python 后端复用工具名称和查询语义、现有 `solution_knowledge` 连接与权限校验，不复制 Node Agent 或开放通用命令执行。

| 工具 | 功能 |
|---|---|
| `dikw_health` | 读取基本可用状态，剔除内部模型与配置 |
| `retrieve_knowledge` | 检索相关段落及页面引用，支持换词继续查询 |
| `list_pages` | 按论文、知识、智慧或全部列目录，返回总数和分页 |
| `read_page` | 读取已索引 Markdown 正文，支持分段续读 |
| `page_links` | 读取入链与出链，用于继续查阅关联知识 |
| `list_wisdom` | 按状态列出智慧条目；适配 Core 0.6.10 的统一页面接口 |

来源 Agent 另外注册 `web_search`（Tavily）、`web_fetch`（Jina）及 `propose_maintenance_action`（仅建议、不直接执行维护）。本次只接入上述六项知识库查询，不需要额外第三方密钥。Core 0.6.10 不提供旧 `/v1/wisdom` 路由，因此 `list_wisdom` 改用 `/v1/base/pages?active=true&layer=wisdom`，支持状态和分页，不接受旧接口的 `kind` 参数。

执行入口为 `assistant_tool_chat.py`，每轮最多4轮工具交互、8次工具调用，再要求模型依据已有资料回答；总查询时间预算120秒（在途 Core 请求最多30秒），工具资料预算80,000字符、单结果24,000字符。目录每页最多50项，检索最多20段，正文一次最多12,000字符。截断与续读位置显式返回。错误不会伪装成空结果，失败不保存半成品问答。

兼容 OpenAI 工具协议（企业 DeepSeek/MiniMax、个人兼容模型）和企业 Ollama 原生工具协议；模型需支持 function calling。个人模型继续使用既有 DNS 固定、禁止重定向的传输。DeepSeek 工具续轮保留其要求的 `reasoning_content`。每次工具调用及最终回答前重新核对实时 KB 角色；未选择知识库时走原普通对话流程。资料中的指令不具备工具授权，工具只访问管理员固定配置的 Core，禁止自定义地址、文件系统、写入和维护动作。历史工具结果不会跨轮自动传给模型。

本次实现不新增数据库迁移或环境变量；继续使用 `SOLUTION_KB_CORE_URL`、`SOLUTION_KB_TOKEN`、`SOLUTION_KB_PUBLIC_URL`。本地合同与接口测试使用隔离 Core/模型响应；生产已完成实际 Core 目录、原文、关联、智慧和检索检查，真实客户账号的生成模型问答仍待验收，详见上述发布记录。

## 失败原因与诊断编号

模型超时、回答输出超限、限流和返回格式异常分别提示，问题草稿保留，并显示诊断编号。管理员可按编号关联本次模型与知识库调用耗时；不记录问题、资料、回答或密钥。页面等待超时则显示客户端请求编号，需核对后台是否已完成。查询和保存边界见[诊断说明](assistant-diagnostics.md)。

## 自动回答方式（开发预览）

数据设置即时说明勾选后的可查询范围，输入框旁常驻显示当前范围；勾选是允许访问，并不强制每轮读取。

| 应用数据选择 | 助手可以使用的内容 |
|---|---|
| 都不选 | 模型通用知识、可用对话及本轮主动提供的资料，不主动查询应用数据 |
| 只选项目管理 | 按问题需要读取当前账号有权查看的项目概况，不查询知识库 |
| 只选知识库 | 按问题需要查询授权知识库，不读取项目管理数据 |
| 两项都选 | 按问题读取相关应用，联合问题可使用两者，仍受各应用权限限制 |

应用数据与联网搜索独立：未勾选不代表禁止联网，是否搜索还取决于回答方式及搜索服务状态。「通用回答」不查询应用或联网；「仅知识库」须启用知识库，只读取该范围。设置保存后用于后续提问。项目数据只读接入、说明与资料识别修正均为开发预览，未部署生产。

默认「自动」，无需每次说明要不要联网。通用问题直接回答，近期信息走公开检索，知识库问题走授权资料；可在高级选项限制方式。知识库数据开关表示允许读取，不代表每个问题都强制查库。每轮显示实际方式与来源。搜索未配置时保留输入并提示联系管理员，预览联网回答逐轮标明未实际联网。本轮需新增迁移 `014`，未部署生产，详见[完整说明](assistant-auto-search.md)。
