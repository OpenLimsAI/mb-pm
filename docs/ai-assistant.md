# AI 助手

个人助手入口为 `/assistant`。正式页面使用门户身份；本地 `/assistant?preview=1` 只演示界面，不调用客户数据或模型。实际部署提交、验证及回滚以[部署交接](部署交接简明.md)和[发布记录](../deploy/parallel-test/README.md)为准。

## 入口与工作界面

- 左侧保留新建任务、数据设置、AI 模型设置、回收站及任务搜索。任务可以置顶、改名；删除位于任务列表，即使旧任务内容打不开，也可移入回收站。
- 中间按“提问＋回答”分轮呈现，加深提问背景；提问正文可直接选中复制，也可点击“复制提问”保留完整原文。回答正文直接讲结果，上方显示实际回答方式与来源。
- 右侧默认展示任务概览；点“查看产物”才打开对应回答。产物页以默认展开的卡片列表展示全部成果，最新在前，标注对应轮次、时间、模型与最终成果；超过4份可按标题或模型查找。切换时正文回到顶部，选中项始终可见。可将一份回答设为最终成果，回到任务时优先显示；其他回答仍在历史中，不自动覆盖最终成果。
- 桌面可拖动对话与结果区之间的分隔线调整宽度，两侧保留最小阅读空间；双击恢复默认。也可选中分隔线后使用左右方向键调整，Home / End 移至两端。布局记在当前浏览器，按登录身份及预览 / 正式环境隔离；关闭、全屏或窄屏展示不丢失原比例。
- 窄屏使用可展开的任务导航及结果抽屉。输入 Enter 发送、Shift＋Enter 换行，中文输入法确认文字不会误发送。

任务项目归类、项目名称、技能功能保持移除。“项目管理”仅作为可选只读数据源，与任务归类无关。

## 回收站

侧栏“任务列表”和“回收站”是两个独立入口，名称不随点击改变。进入回收站后，中间主区展示已删除任务列表及删除时间，不自动打开第一项；列表搜索、刷新与加载更多都只作用于已删除任务。无记录显示“回收站为空”，搜索无结果、加载中和读取失败分别提示，不进入新建任务欢迎页。

选择查看某项已删除任务后，仅能阅读既有对话和成果、复制或导出，并可返回回收站列表或确认恢复；重新问答、改稿、记忆和任务编辑需恢复后进行。列表恢复不依赖读取完整历史，旧资料失权或详情打不开时仍可操作本人任务摘要。恢复后任务回到任务列表，当前回收站继续显示剩余任务，恢复最后一项后显示空态。

切换两个入口会取消当前视图的详情、来源和列表响应接收，避免晚到结果串到另一视图。异步删除/恢复完成时核对视图与当前任务，保护其他任务的未发送草稿。操作失败保留原记录与重试入口；不使用列表失败冒充空回收站。代码行为与实际部署状态分别记录。

## 数据范围与回答方式

| 数据设置 | 可使用的应用数据 |
|---|---|
| 都不选 | 不查询应用数据，可依据一般知识、可用对话及本轮资料回答 |
| 只选项目管理 | 按需读取当前账号有权访问的项目概况 |
| 只选知识库 | 按需查询当前账号已授权的知识库 |
| 两项都选 | 按问题读取一个或两个应用，分别检查权限 |

默认“自动”按当前问题和上一轮范围判断；可选“通用回答”“仅知识库”“联网检索”。多轮追问延续已有范围；明确要求不联网时遵守该要求。规则判断仍可能不符合预期，每轮可展开“换个范围重新回答”，明确选择新范围生成新一轮，旧回答保留。

数据范围、回答方式和模型共同组成当前提问设置。修改任一项或更新同一模型的配置版本后，旧设置的检查提示立即失效，并重新检查；晚到的旧检查结果不会覆盖新设置，也不会继续按旧范围发送。若修改发生在发送前检查期间，需要用户再次点击回答；保存设置不会自动调用模型。配置错误只显示一次，直接提供数据设置或模型设置入口；慢到的模型设置不会覆盖任务已保存的模型选择。真正已经提交的请求失败仍保留，避免把设置更新误当作请求成功。

来源提示依据实际使用记录，不把勾选等同于已查询。通用回答标明“未查询知识库 · 未联网”；正文不主动解释后台空字段或缺少工具。真正影响答案的证据缺口仍应说明。

知识库统计使用“资料份数”，包含论文、监管文档等，不把 source 层全部记录叫作学术论文。每轮区分目录条目、检索命中、原文阅读和能够识别的路径引用；展示的是实际交给模型的有界工具结果，不代表检索了全库。来源截断会标明。模型未输出可识别来源路径时，不能把其文字推断成已核验引用。来源按钮在助手内分段打开原文，每次读取重新检查权限。

公开联网与应用数据独立；自动或联网模式需要可用搜索配置。默认搜索跟随当前选中的官方模型账户：DeepSeek 使用 DeepSeek，Kimi 使用同区域 Kimi；不支持的模型会明确提示。数据设置只管理项目管理和知识库，不展示联网状态。搜索服务名称在回答方式旁显示。官方搜索和可选 Tavily 的配置见[自动问答与联网搜索](assistant-auto-search.md)。不会从其他账号或模型借用密钥；管理员显式配置 Tavily 时使用独立搜索服务，不在调用失败后悄悄换服务。

## 发送、停止与失败恢复

正式提交先保存为后台请求，再返回状态。页面显示排队、等待模型、有界恢复、生成、保存，以及已用时间。官方 DeepSeek 普通回答支持逐段正文；推理过程不显示。完整保存前的内容明确标为未完成稿。

服务端确认接收后，上方显示“本轮提问”，输入框清空本次已发送的问题和资料；提交尚未确认时保留输入。等待期间新写的草稿不被清除；请求失败或停止后，仅在输入框没有新草稿时恢复原问题及资料，供修改重试。刷新恢复运行中的请求也不会重复填入已发送内容。

- “停止生成”可停止本人排队或运行请求，释放任务名额。后台用状态和工作令牌阻止旧进程继续写入，连接在后续检查时关闭；已发生的服务商计算或计费不能撤回。
- 超时、输出上限和主动停止可保留已生成的安全正文。用户选择“根据草稿重新整理”时创建一条新请求，重新核对权限、应用范围和事实后生成完整回答；这不是原回答的直接接尾。长草稿最多带入16,000字符，保留首尾并明确标记被省略的中段，不推断省略内容。临时输入已清理或没有安全正文时不提供该操作。
- “重新生成”和“根据草稿重新整理”均由用户操作触发。断网或丢失提交响应只查询原请求；认证、额度、限流、网络和超时错误不会自动重新调用模型。仅已验证的官方 DeepSeek 输出超限可按下述规则在原请求内自动恢复一次。
- 刷新或重新登录后可恢复请求状态。明确失败后新提交使用新编号；每项任务同一时间只有一个生成请求。
- 同一请求失败只显示一个错误区域，区分超时、回答超限、限流、认证和搜索问题，集中提供未完成草稿、诊断信息复制及对应处理入口；取消不重复显示失败告警。管理员按编号查询运行记录。

默认总时限300秒，连接15秒，读取空闲120秒；心跳和自动恢复不延长原总时限。只有官方 HTTPS DeepSeek 地址、已验证的 `deepseek-v4-pro` / `deepseek-flash` 模型应用统一策略：个人普通问答与知识库问答默认较低思考强度、8192 token预算；明确要求深入分析/详细推导时提高为较高思考强度、16384预算，否定要求不触发高强度。其他服务商、代理地址及未知模型保留原有参数。

同一后台请求在模型明确返回输出超限后，最多自动恢复一次，普通问答和知识库共用该次数。仅在原时限还足够且未停止、未失权时进行；恢复关闭思考、使用16384预算，并限制为简短结构化回答。知识库复用本轮已授权、已执行的资料，不再调用工具，截断的工具参数不执行。有正文时先清除推理内容并检查来源与权限，保留符合条件的未完成正文，再尝试追加剩余内容；新内容来源无效或再次超限时，不能作为完整回答发布。没有可见正文时尝试直接生成简短答案，不承诺一定能恢复。

知识库草稿仅保留通过现有路径来源检查和权限检查的可见正文；断裂的路径、未读来源和工具决策文字不冒充答案。路径匹配并不等于事实已全面核验。恢复中若上游认证、限流或拒绝请求，保留此前合法写入的草稿和真实失败分类；业务权限撤回、停止或租约失效仍受原围栏限制，不能继续发起恢复或覆盖已取消状态。

服务重启或租约过期后，运行请求标为中断，供用户重试；排队超过10分钟结束等待。生成期间任务设置及删除受保护，先停止生成再操作。旧同步 `/messages` 保留兼容，新页面使用 `/requests`。

2026-11-04 的统一输出策略、有界恢复与错误去重已实现；生产是否部署及真实模型验收以独立发布回执为准。本次不新增数据库迁移。

## 草稿、资料与长对话

未发送的问题和本轮资料按账号、环境、任务保存到当前浏览器，7天过期；可以清空草稿。正式提交的输入由服务端持久保存。回答方式、数据范围和模型偏好按用户/任务保存；预览与正式环境隔离，不保存模型密钥。

Word、PDF、Markdown 在本机解析，不上传原始文件。单文件最多20MB，本轮正文最多20,000字；长文完整解析后列出可选片段，附提取正文的字符位置，发送前可预览和编辑。未选择的片段不会发送，超限不会静默截断。字符位置不是 PDF 页码；扫描 PDF 需先 OCR。

任务设置中的“任务摘要”记录长期目标、术语和约定。回答旁可选择“记入任务记忆”，归入目标、约束、已确认结论或待解决问题，编辑内容并预览合并结果后明确保存；记录来源轮次，不从提问自动推断已确认结论。摘要最多6,000字，作为用户上下文随问题发送，不是已验证证据；涉及应用事实仍按当前范围重新查询。保存核对任务版本，冲突时保留编辑供核对。不会后台额外调用模型自动改写摘要。

## 六项问答与成果改进

- 联网合成带入有界任务指引、已确认摘要和同任务安全历史，支持“第二项”等追问。公开搜索只接收独立查询词，任务偏好、基稿和附带资料不自动送给搜索服务。旧答案只帮助理解指代，不能替代本轮来源；上下文截取时明确说明。
- 个人知识库问题在模型回答前执行当前授权检索；数量/完整目录问题走目录，其余按主题查询并最多补搜一次、预读两页。计入原有8次工具、80,000字符和总时限。正文缺少相关片段时正常说明证据不足，不让模型无证据作库内结论。
- 来源显示实际交给模型的摘录。字符位置只在工具确实提供时显示，未知位置不猜页码。非目录回答检查引用路径属于本轮可用正文；路径匹配不等于结论语义已验证，用户应对照片段核实。
- 导入使用完整提取正文，保留 Markdown 标题层级及段落分隔，再按现有预算选片段；不再只拼接章节内容导致丢标题。复杂 PDF 排版、扫描图像和 OCR 不在本次能力内。
- 右侧“基于此稿修改”明确选择原稿，提交仅传本任务成果编号；服务端重新检查所属任务、身份及来源权限，加载原稿并生成新回答。新稿记录父稿编号，原稿及原最终成果选择保留，需用户明确选择新版为最终成果。切换任务、失败、停止和重试继续保护基稿关系。
- 检索增加小范围中英术语映射、正文词法相关性筛选、去重和排序。标题相符只作为读取候选，不能代替正文依据；分值不是置信度。本次没有引入新向量库或额外排序模型；检索不额外生成答案，输出超限仅按上文规则最多自动恢复一次。

具体实施、验收样例和技术学习材料见[六项改进指南](assistant-six-improvements.md)。本节描述代码能力；实际上线与客户验收以独立发布回执为准。

问题最多12,000字，任务名称200字、指引4,000字；每任务最多100轮。模型带最近3轮的有界上下文；对于“这个问题”等追问，额外保留最多4个去重的用户主题问题，避免反复重答挤掉原始主题。跨回答方式仅在原来源仍获本轮允许时带用户提问以理解追问，不复用旧应用回答或附件作证据；遇到来源范围边界停止向前取主题。公开搜索仅可接续原本公开的联网问题，不把私有应用问题或附件发送给搜索服务。

任务搜索支持标题、提问、回答和附带资料，返回匹配片段。正文命中先按历史权限校验，不泄露已失权内容的命中数量或片段。任务摘要、置顶和最终成果随任务版本保存，冲突时先刷新核对。

## 权限与历史任务

任务以 IAM issuer/sub 隔离；所有写操作要求同源门户会话，并执行首次改密约束。通用问答不要求 PM 或 KB 角色。项目数据依赖现有有效 PM 绑定及行级范围；知识库实时核对 KB 角色。勾选数据源不授予权限。

历史详情、来源阅读、请求片段和续写统一核对实际使用范围；权限撤回后不继续提供受限内容。旧项目回答缺少可验证范围时仍禁止读取，保留任务摘要及回收站操作，不强行放开历史。恢复任务不代表恢复数据阅读权限。原历史和业务数据不批量重写。

## 管理员运行面板

门户“AI 设置”的“助手运行管理”仅实时 IAM `admin` 可查看。显示最近24小时请求状态、失败分类、提交/完成时间、处理时长及可用时的首段等待时间；按完整诊断编号定位，最多返回50条。面板不展示问题、正文、附件、账号身份或密钥。操作权限在服务端检查，界面隐藏不替代鉴权。

可以调整每人待处理上限（1–20，默认3）、每人同时生成上限（1–4，默认1）、全局排队上限（1–1000，默认100）。两个实例通过数据库事务锁协调准入和认领，同一用户不会占满所有名额；降低上限不主动终止现有回答。

请求重复内容保留期默认0，表示不清理。管理员可配置7–365天，再明确确认清理；每次最多处理1000条已结束请求。仅移除重复输入和未完成稿，保留诊断/幂等记录及正式任务问答；清理后的未完成稿无法继续。当前不自动删除历史消息，不按保留期清空客户数据。

发送前预检只检查配置、模式与当前权限，不发起付费模型测试或实际搜索。“配置检查通过”不等同于服务商可用，真实认证、额度及响应仍以请求结果为准。

## DIKW 查询工具

六项只读工具为 `dikw_health`、`retrieve_knowledge`、`list_pages`、`read_page`、`page_links`、`list_wisdom`。只访问管理员配置的 Core，不接收用户自定义地址，不提供 shell、文件系统或业务写入。

最多4轮工具交互、8次工具调用；工具资料预算80,000字符，单结果24,000字符，目录每页最多50项，检索最多20段，正文每次最多12,000字符。资料超限显式标记，错误不伪装为空结果。每次工具执行及保存前检查权限。Core0.6.10的智慧列表通过统一页面接口读取。

## 接口与升级

- `/api/v1/assistant/tasks`：列表、创建；`/{id}`：读取和带 revision 修改。
- `/{id}/requests`：后台提交；`/active` 和 `/{request_id}`：恢复/轮询；`/{request_id}/cancel`：停止。
- `/{id}/sources`：读取已保存来源路径的原文；`/{id}/trash`、`/{id}/restore`：本人回收站操作。
- `/preflight`：无付费调用预检；`/operations`、`/operations/settings`、`/operations/prune`：管理员诊断、容量与显式清理。
