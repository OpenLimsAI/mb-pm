# AI 助手

本轮代码和本地预览已实现，未推送、未部署生产，也未执行生产迁移。

## 入口与工作界面

应用工作台最前面的「AI 智能版块」提供 AI 助手入口。独立地址为 `/assistant`，本地界面预览为 `/assistant?preview=1`。界面采用系统深蓝顶栏、浅蓝导航与白色工作区。

- 顶部工具栏：应用工作台、当前登录账号与主题切换。
- 左侧导航：新建任务、数据设置、AI 模型设置、回收站和任务搜索。
- 中间对话：独立任务标题、消息历史、资料上下文、问题输入与模型选择。
- 右侧结果：在概览与产物之间切换，查看任务指引及独立回答，复制或导出 Markdown；支持收起和放大。

桌面并列显示三栏；较窄窗口将结果改为侧边抽屉，手机上任务导航也可展开和收起。

## 使用流程

1. 新建任务，填写名称，可选填个人项目分组和任务指引。分组不是项目管理系统中的正式业务项目。
2. 在「数据设置」中选择项目管理、知识库或两者，后续提问只读取所选应用的数据；不选择时不读取应用数据。设置保存在当前浏览器，按用户和预览环境区分。
3. 输入本轮目标，明确发送后才请求模型。
4. 可在任务资料中导入 Word（`.docx`）、PDF、Markdown，或粘贴正文。导入沿用研究报告的本机解析器，不上传原始文件；发送时只带弹窗内确认的正文。单文件最多20MB，本轮参考正文最多20,000字，超限需截取后再使用。扫描PDF需先OCR。
5. 选择企业默认模型或自己的个人模型，发送问题。每项任务保存独立历史，每轮回答形成一份可查看、复制和导出的 Markdown 产物。
6. 可以切换任务继续工作。迟到的回答只更新原任务，其他任务的输入草稿保留。问题失败时保留当前输入，重试复用请求标识；有版本冲突时先刷新核对。
7. 任务设置支持更名、项目和指引修改。删除任务需确认，任务会移至回收站，仍可恢复，对话和产物会保留。

问题最多12,000字，任务名称/项目最多200字，任务指引最多4,000字。正式接口每项任务最多100轮，模型最多带最近3轮的问题节选；选择应用数据或历史包含应用数据时，不带历史回答或资料，以免沿用已取消选择或已失权的数据。未选择应用且近期历史均未使用应用数据时，带历史回答节选。导入资料、用户指引和历史均为上下文，不作为已验证证据。

## 模型与数据边界

个人模型配置与工作台 AI 设置、研究报告共用；密钥由后端加密保管，浏览器只接收是否已设置标记。选择「企业默认模型」可显式使用企业配置，不因返回设置页而被个人默认选择覆盖。普通助手不提供「仅检索资料」选项。

正式任务使用门户 Cookie 身份，按 IAM issuer/sub 隔离，不要求 PM 或知识库角色。预览使用独立的 `mberp:assistant:preview:v1:<namespace:user>` 浏览器键，带入门示例，刷新可恢复。本地预览不调用真实模型、不接收真实密钥，其回答明确标注为流程演示。

选中项目管理后，每次提问按实时 IAM 角色和项目、任务可见范围读取项目基本信息及任务摘要，最多各 100 条；首次使用需先进入项目管理关联用户。选中知识库后，沿用知识报告的实时 KB 权限和连接配置，读取有效论文总数，并按问题检索最多 4 篇，每篇最多 5,000 字。超限会标记资料不完整，权限或连接不可用时返回错误。用户主动附加的本轮资料仍会发送给模型。预览不读取真实应用数据。助手不执行联网搜索、邮件、定时调度或业务数据修改。

## 接口与升级

`/api/v1/assistant/tasks` 提供列表、创建、读取和修改；`/{id}/messages` 发送问题，`/{id}/trash` 与 `/{id}/restore` 软删除和恢复。创建采用 UUID，修改和提问使用 revision，提问另带 request_id。完成后的同内容重试直接返回保存结果；并发模型生成只保证不会重复保存消息，不承诺外部推理恰好执行一次。

010 迁移新增 `assistant_tasks` 与 `assistant_messages`、归属索引、消息顺序和请求唯一约束。模型等待前释放读事务，返回后重新校验归属、任务状态和版本，再原子保存一对问答。012 迁移为消息记录增加数据范围，用于重试校验；正式运行需先备份并迁移至 012。本次更改尚未部署。
