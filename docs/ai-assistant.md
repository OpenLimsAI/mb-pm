# AI 助手

本轮代码和本地预览已实现，未推送、未部署生产，也未执行生产迁移。

## 入口与工作界面

应用工作台最前面的「AI 智能版块」提供 AI 助手入口。独立地址为 `/assistant`，本地界面预览为 `/assistant?preview=1`。界面采用系统深蓝顶栏、浅蓝导航与白色工作区。

- 顶部工具栏：AI 模型设置、应用工作台。
- 左侧导航：新建任务、项目分组、常用技能、任务资料、任务搜索和回收站。
- 中间对话：独立任务标题、消息历史、资料上下文、问题输入与模型选择。
- 右侧结果：在概览与产物之间切换，查看任务指引及独立回答，复制或导出 Markdown；支持收起和放大。

桌面并列显示三栏；较窄窗口将结果改为侧边抽屉，手机上任务导航也可展开和收起。

## 使用流程

1. 新建任务，填写名称，可选填个人项目分组和任务指引。分组不是项目管理系统中的正式业务项目，也不自动同步业务记录。
2. 输入本轮目标，或选择资料解读、撰写报告、任务规划、会议纪要等技能模板；模板只填入问题，明确发送后才请求模型。
3. 可在任务资料中导入 Word（`.docx`）、PDF、Markdown，或粘贴正文。导入沿用研究报告的本机解析器，不上传原始文件；发送时只带弹窗内确认的正文。单文件最多20MB，本轮参考正文最多20,000字，超限需截取后再使用。扫描PDF需先OCR。
4. 选择企业默认模型或自己的个人模型，发送问题。每项任务保存独立历史，每轮回答形成一份可查看、复制和导出的 Markdown 产物。
5. 可以切换任务继续工作。迟到的回答只更新原任务，其他任务的输入草稿保留。问题失败时保留当前输入，重试复用请求标识；有版本冲突时先刷新核对。
6. 任务设置支持更名、项目和指引修改。移到回收站后只读，恢复后继续使用，对话和产物保留。

问题最多12,000字，任务名称/项目最多200字，任务指引最多4,000字。正式接口每项任务最多100轮，模型只带最近3轮的有界历史节选，长历史不会完整重发。导入资料、用户指引和历史均为上下文，不作为已验证证据。

## 模型与数据边界

个人模型配置与工作台 AI 设置、研究报告共用；密钥由后端加密保管，浏览器只接收是否已设置标记。选择「企业默认模型」可显式使用企业配置，不因返回设置页而被个人默认选择覆盖。普通助手不提供「仅检索资料」选项。

正式任务使用门户 Cookie 身份，按 IAM issuer/sub 隔离，不要求 PM 或知识库角色。预览使用独立的 `mberp:assistant:preview:v1:<namespace:user>` 浏览器键，带入门示例，刷新可恢复。本地预览不调用真实模型、不接收真实密钥，其回答明确标注为流程演示。

当前助手进行文本分析与撰写，不执行联网搜索、邮件、定时调度、业务数据修改或外部工具操作，也不自动读取其他应用资料。未提供的连接器、语音和定时功能没有设置虚假可用入口。

## 接口与升级

`/api/v1/assistant/tasks` 提供列表、创建、读取和修改；`/{id}/messages` 发送问题，`/{id}/trash` 与 `/{id}/restore` 软删除和恢复。创建采用 UUID，修改和提问使用 revision，提问另带 request_id。完成后的同内容重试直接返回保存结果；并发模型生成只保证不会重复保存消息，不承诺外部推理恰好执行一次。
