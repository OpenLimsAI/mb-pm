# AI 助手

个人助手入口为 `/assistant`。正式页面使用门户身份；本地 `/assistant?preview=1` 只演示界面，不调用客户数据或模型。实际部署提交、验证及回滚以[部署交接](部署交接简明.md)和[发布记录](../deploy/parallel-test/README.md)为准。

## 入口与工作界面

- 左侧保留新建任务、数据设置、AI 模型设置、回收站及任务搜索。任务可以置顶、改名；删除位于任务列表，即使旧任务内容打不开，也可移入回收站。
- 中间按“提问＋回答”分轮呈现，加深提问背景；回答正文直接讲结果，上方显示实际回答方式与来源。
- 右侧默认展示任务概览；点“查看产物”才打开对应回答。可将一份回答设为最终成果，回到任务时优先显示；其他回答仍在历史中，不自动覆盖最终成果。
- 窄屏使用可展开的任务导航及结果抽屉。输入 Enter 发送、Shift＋Enter 换行，中文输入法确认文字不会误发送。

任务项目归类、项目名称、技能功能保持移除。“项目管理”仅作为可选只读数据源，与任务归类无关。

## 数据范围与回答方式

| 数据设置 | 可使用的应用数据 |
|---|---|
| 都不选 | 不查询应用数据，可依据一般知识、可用对话及本轮资料回答 |
| 只选项目管理 | 按需读取当前账号有权访问的项目概况 |
| 只选知识库 | 按需查询当前账号已授权的知识库 |
| 两项都选 | 按问题读取一个或两个应用，分别检查权限 |

默认“自动”按当前问题和上一轮范围判断；可选“通用回答”“仅知识库”“联网检索”。多轮追问延续已有范围；明确要求不联网时遵守该要求。规则判断仍可能不符合预期，每轮可展开“换个范围重新回答”，明确选择新范围生成新一轮，旧回答保留。

来源提示依据实际使用记录，不把勾选等同于已查询。通用回答标明“未查询知识库 · 未联网”；正文不主动解释后台空字段或缺少工具。真正影响答案的证据缺口仍应说明。

知识库统计使用“资料份数”，包含论文、监管文档等，不把 source 层全部记录叫作学术论文。每轮区分目录条目、检索命中、原文阅读和能够识别的路径引用；展示的是实际交给模型的有界工具结果，不代表检索了全库。来源截断会标明。模型未输出可识别来源路径时，不能把其文字推断成已核验引用。来源按钮在助手内分段打开原文，每次读取重新检查权限。

公开联网与应用数据独立；自动或联网模式需要可用搜索配置。DeepSeek 官方搜索和可选 Tavily 的配置见[自动问答与联网搜索](assistant-auto-search.md)。不会从其他账号或模型借用密钥，也不自动切换搜索服务。

## 发送、停止与失败恢复

正式提交先保存为后台请求，再返回状态。页面显示排队、等待模型、生成、保存，以及已用时间。官方 DeepSeek 普通回答支持逐段正文；推理过程不显示。完整保存前的内容明确标为未完成稿。

- “停止生成”可停止本人排队或运行请求，释放任务名额。后台用状态和工作令牌阻止旧进程继续写入，连接在后续检查时关闭；已发生的服务商计算或计费不能撤回。
- 超时、输出上限和主动停止可保留已生成的安全正文。“接着草稿继续”创建一条新请求，服务端按同一任务读取原稿并重新核对权限；不会把草稿当作已核验事实。
- 重新生成、继续草稿均由用户操作触发。断网或丢失提交响应只查询原请求，不自动重复调用付费模型。
- 刷新或重新登录后可恢复请求状态。明确失败后新提交使用新编号；每项任务同一时间只有一个生成请求。
- 错误区域区分超时、回答超限、限流、认证和搜索问题，提供诊断信息复制及对应处理入口。管理员按编号查询运行记录。

默认总时限300秒，连接15秒，读取空闲120秒；心跳不无限延长总时限。普通 DeepSeek 问答使用较低思考强度与8192 token预算，明确要求深入分析/详细推导才提高到16384；否定要求不触发高强度。输出上限仍可能发生，应缩小范围或继续未完成稿。

服务重启或租约过期后，运行请求标为中断，供用户重试；排队超过10分钟结束等待。生成期间任务设置及删除受保护，先停止生成再操作。旧同步 `/messages` 保留兼容，新页面使用 `/requests`。

## 草稿、资料与长对话

未发送的问题和本轮资料按账号、环境、任务保存到当前浏览器，7天过期；可以清空草稿。正式提交的输入由服务端持久保存。回答方式、数据范围和模型偏好按用户/任务保存；预览与正式环境隔离，不保存模型密钥。

Word、PDF、Markdown 在本机解析，不上传原始文件。单文件最多20MB，本轮正文最多20,000字；长文完整解析后列出可选片段，附提取正文的字符位置，发送前可预览和编辑。未选择的片段不会发送，超限不会静默截断。字符位置不是 PDF 页码；扫描 PDF 需先 OCR。

任务设置中的“任务摘要”记录长期目标、术语和约定，可从既有提问整理草稿后由用户编辑保存。摘要最多6,000字，作为用户上下文随问题发送，不是已验证证据；涉及应用事实仍按当前范围重新查询。不会后台额外调用模型自动改写摘要。

问题最多12,000字，任务名称200字、指引4,000字；每任务最多100轮。模型带最近3轮的有界上下文；应用历史只在原来源仍获本轮允许时带用户提问以理解追问，不复用旧应用回答或附件作证据。

任务搜索支持标题、提问、回答和附带资料，返回匹配片段。正文命中先按历史权限校验，不泄露已失权内容的命中数量或片段。任务摘要、置顶和最终成果随任务版本保存，冲突时先刷新核对。

## 权限与历史任务

任务以 IAM issuer/sub 隔离；所有写操作要求同源门户会话，并执行首次改密约束。通用问答不要求 PM 或 KB 角色。项目数据依赖现有有效 PM 绑定及行级范围；知识库实时核对 KB 角色。勾选数据源不授予权限。

历史详情、来源阅读、请求片段和续写统一核对实际使用范围；权限撤回后不继续提供受限内容。旧项目回答缺少可验证范围时仍禁止读取，保留任务摘要及回收站操作，不强行放开历史。恢复任务不代表恢复数据阅读权限。原历史和业务数据不批量重写。

## 管理员运行面板

门户“AI 设置”的“助手运行管理”仅实时 IAM `admin` 可查看。显示最近24小时请求状态、失败分类、提交/完成时间、处理时长及可用时的首段等待时间；按完整诊断编号定位，最多返回50条。面板不展示问题、正文、附件、账号身份或密钥。操作权限在服务端检查，界面隐藏不替代鉴权。

可以调整每人待处理上限（1–20，默认3）、每人同时生成上限（1–4，默认1）、全局排队上限（1–1000，默认100）。两个实例通过数据库事务锁协调准入和认领，同一用户不会占满所有名额；降低上限不主动终止现有回答。

请求重复内容保留期默认0，表示不清理。管理员可配置7–365天，再明确确认清理；每次最多处理1000条已结束请求。仅移除重复输入和未完成稿，保留诊断/幂等记录及正式任务问答；清理后的未完成稿无法继续。当前不自动删除历史消息，不按保留期清空客户数据。

发送前预检只检查配置、模式与当前权限，不发起付费模型测试或实际搜索。“配置检查通过”不等同于服务商可用，真实认证、额度及响应仍以请求结果为准。

## DIKW 查询工具

六项只读工具为 `dikw_health`、`retrieve_knowledge`、`list_pages`、`read_page`、`page_links`、`list_wisdom`。只访问管理员配置的 Core，不接收用户自定义地址，不提供 shell、文件系统或业务写入。

最多4轮工具交互、8次工具调用；工具资料预算80,000字符，单结果24,000字符，目录每页最多50项，检索最多20段，正文每次最多12,000字符。资料超限显式标记，错误不伪装为空结果。每次工具执行及保存前检查权限。Core0.6.10的智慧列表通过统一页面接口读取。

## 接口与升级

- `/api/v1/assistant/tasks`：列表、创建；`/{id}`：读取和带 revision 修改。
- `/{id}/requests`：后台提交；`/active` 和 `/{request_id}`：恢复/轮询；`/{request_id}/cancel`：停止。
- `/{id}/sources`：读取已保存来源路径的原文；`/{id}/trash`、`/{id}/restore`：本人回收站操作。
- `/preflight`：无付费调用预检；`/operations`、`/operations/settings`、`/operations/prune`：管理员诊断、容量与显式清理。
