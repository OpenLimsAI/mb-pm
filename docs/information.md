# 信息获取 · 交互首版

[返回功能说明](features.md) · [本地开发](development.md)

根据「信息获取App」讨论中的融合版设计接入。用户确认本轮先交付可操作界面，真实采集后续再做。

## 入口与身份

- 工作台「工作应用」→「信息获取」→ `/launch/information`，刷新准入后打开固定的 `/information`。
- 信息获取与门户同源，复用门户会话和强制改密守卫，不要求先开通 PM 或 KB，也不创建 PM 成员或授予知识库权限。
- 应用顶部显示实际门户登录姓名，浅金色「应用工作台」返回门户；PM 域名上的旧路径返回门户应用。
- 仅在开发且不启用真实 API 时可用 `/information?preview=1` 体验未登录预览。

## 首版可体验内容

| 界面 | 可操作内容 |
| --- | --- |
| 工作台 | 更新概览、待阅读事项及快捷入口 |
| 情报收件箱 | 筛选、详情、变化对照、已读、稍后看与撤销 |
| 批量收录 | 范围与目标演示文件夹、发现清单、进度、暂停续跑、失败重试及结果查看 |
| 知识资料 | 查找演示资料、原文和问答版本、解析状态及演示重试 |
| 信息源 | ICH Q/S/E/M 范围、频率和目录检查状态、来源配置与演示启停 |
| 我的关注 | 个人关注范围与提醒偏好 |
| 运行与费用 | 演示运行记录及可调整的费用测算 |

全局持续标注演示状态；演示进度、文件夹、入库、解析、运行及费用均不能作为实际系统完成记录。
超时显示本次未能判断，不等同于“没有更新”。关闭监控不删除资料，关闭提醒不等同于关闭监控。
成本是用户可改的假设测算，不是实时供应商报价或真实账单。

## 数据边界

本轮不增加采集、调度、文件下载、知识库入库、站外通知或模型接口。演示中的资料不代表当前 ICH 官方状态。
不会读写生产知识库或原论文文件夹，不触发模型费用，不读取或复制 Core 服务令牌。

界面状态仅保存在浏览器本地，命名空间来自后端对已验证 IAM issuer、组织和 subject 的 SHA-256。
切换身份重新挂载界面并取消演示计时器；改登录名不会错误切换为其他人的数据。
旧后端未返回隔离键或界面预览时仅使用内存状态，不回落到共享开发账号；无法保存时明确提示。
存储不含密码、令牌或原始身份声明。来源 URL 仅允许 HTTP(S)；展示使用 React 文本转义。

## 后续真实服务

后续需单独实现并验收：ICH 官方适配、文件哈希与版本归档、后台任务、失败恢复、真实文件夹与知识库入库、解析索引、权限审计及实际用量。
当前知识库文件夹为 BFF 的共享目录，不等同于 Core 文件夹；不能仅把资料送进 Core 就声称已进入指定知识库文件夹。
上线真实服务前还须明确角色、采集频率、可访问范围和转换服务配置。

本地验证、GitHub 合并及客户生产发布是不同状态；本轮没有自动部署客户生产系统。
