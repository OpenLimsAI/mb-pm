# 项目执行与协同

[返回功能说明](features.md)。本页描述本轮代码能力；生产版本与真实验收以发布回执为准。

## 日常处理

- 顶栏搜索项目、任务、里程碑及负责人，任务结果直接打开详情。项目任务地址支持 `?tab=wbs&task=任务ID`；首页风险可查看完整列表并直达任务。
- 项目、任务页可保存多套命名视图，按当前账号存入服务端并在其他设备恢复；视图不会授予额外数据权限。
- 普通成员只提交有权修改的执行字段，计划日期只读；进展、工时、实际花费及进展说明同次保存。未填写的花费与明确填写 0 区别保留。
- 任务具有修订号；抽屉保存携带当前版本，多人修改冲突后保留本次草稿，核对最新值后处理。页面显示最近成功同步时间，每分钟及返回窗口时刷新可见数据；同步失败保留上次数据并可重试。
- API 模式以服务端返回的业务日期统一首页、工作台、任务和通知，业务日期及时区可在同步状态提示查看；跨浏览器时区保持同一日期口径。
- 已完成、已验证均不再计为未完成逾期；日期逾期与显式延迟/阻塞在关注汇总中只计一次。

## 协作与交付

任务内提供讨论、@参与人、进展记录和字段前后值时间线。文件及链接交付物保留版本与提交说明，文件下载仍检查当前任务可见权限。关键里程碑可配置验收人与必需交付数量，提交后由指定人员验收；普通任务继续直接更新。

站内通知包含到期、逾期、任务指派、@及等待验收，可切即时、每日汇总或暂停，支持已读及暂缓。站内提醒需要打开应用；本轮不发送外部邮件、短信或飞书消息。

## 计划与资源

项目「延迟推演」可编辑前置任务日期，预览后续任务与项目完工影响，锁定不可移动节点；确认后一次应用。确认时校验计划指纹，有并发变更则重新预览，不覆盖其他人的调整。

工作日历支持工作周、节假日和例外工作日。默认保留自然日以兼容既有计划，选择工作周后排程、CPM与负荷共用相同日历。

新建基线保存全任务计划、负责人、工时预算、任务成本预算、依赖及日历，可查看新增、删除与字段差异；历史仅含里程碑的基线继续可读，不伪造过去未保存的信息。

人员负荷纳入研发、生产、QA及协作者，剩余工作量按参与人分摊到未来工作日；每周容量及请假存入服务端。变更项目日历和容量后重新计算负荷。推荐改派沿用项目团队及专业范围校验。

## 项目跟进

项目详情「项目跟进」提供风险、问题和决策台账，记录负责人、严重度、期限、措施与关闭结果；管理者维护，可见项目成员读取。

费用台账分为实际明细、待付款和剩余费用估计，支持日期、类别、关联任务及凭据链接。项目已花费仍来自任务实际花费合计，实际明细用于核对，不再次累加；完工预测为任务实际花费加待付款与剩余估计。待付款和剩余估计应分别维护，避免重复计入同一笔未来费用。

数据质量页列出可直接修正的数据缺口；变更页从真实活动和审计记录生成指定时间范围的记录及周报。上线前未采集的历史字段变化不能补算。

## 升级及回滚

新协作、日历、容量、台账、通知及视图表通过维护身份执行 `python -m app.db.upgrade --schema-only` 建立；任务新增修订号，审计对象ID加宽。本次仅执行加法结构升级，跳过历史排序和团队回填。运行服务继续使用 DML 角色，不授予建表权限。发布前加密备份并验证隔离恢复。

旧镜像回滚时保留新增表与列，禁止以旧备份覆盖发布后新增数据。旧版本无法展示新增模块，恢复新版本后仍可读取其记录。
