# 知识源研究工作区：20 项增强与验收

日期：2026-11-04（America/New_York）。本文对应本轮代码实现与验证入口，尚不代表最终主分支已合并、生产镜像已构建或生产已部署；精确提交、环境验收和数据保留以独立发布回执为准。

## 用户流程

从来源、链接、DOI/PMID 或 PDF 收录资料，在同一文献列表检索、分类和阅读。文件夹、标签、共享元数据及原件沿用知识库数据；智能集合和阅读进度属于本人。定期采集沿用已有显式设置，研究模型仅由用户主动发起。

| 编号 | 功能 | 实现与验收行为 |
|---|---|---|
| 1 | 全文检索和定位 | 查询标题、编号、元数据、共享标签及已建立索引的正文；本人笔记通过明确原文链接关联命中。显示片段和真实字符位置，以及正文索引覆盖率。笔记联想有数量上限时明确提示缩小范围。 |
| 2 | 页内阅读 | 列表内阅读提取正文，按段加载；PDF.js 分页绘制受保护原件，支持页码和缩放。知识库阅读链接保留版本/字符位置，可进入既有中英阅读。 |
| 3 | 智能集合 | 持久保存本人动态条件，集合与实际文件夹分开；集合文本与当前搜索按 AND 组合，目录与标签约束共同生效。删除集合不删除资料。 |
| 4 | 阅读队列 | 待读、在读、读完和稍后；保存正文位置与 PDF 页码。同一原件入库前后共用阅读状态，新版不继承旧版的读完状态。自动位置保存不能覆盖较新的显式状态。 |
| 5 | 规则归档 | 预览匹配和目标目录后执行；启用后仅处理新收录资料，增加关联。每批最多 500 篇，保留部分成功的撤销凭证。原件保存与归档结果分别记录。 |
| 6 | 单篇资料卡 | 展示并可更正标题、作者、年份、DOI、摘要；指南的官方编号、阶段、来源和原件版本单独展示。已注册且有共享编辑权限的资料可保存更正；共享元数据使用知识库修订号，冲突不覆盖。 |
| 7 | 文件管理操作 | 目录树展开、拖拽加入分类、Shift 拖拽从当前目录移动、Shift 范围勾选、右键操作、搜索与上下篇键盘入口；窄屏保留批量操作。 |
| 8 | 统一收录 | DOI、PMID、HTTPS 链接、官方搜索结果和多份 PDF 进入同一入口。目录搜索只预览，收录/下载/索引分别选择。手动 PDF 先保存原件和正文，真实显示待注册状态，不隐式启动 Core 全库增量索引；资料详情需另行明确确认后，由后台跟踪真实 Core 任务，成功和活跃注册均确认后才显示可问答。 |
| 9 | 共用标签 | 列表筛选、单篇编辑和所选资料批量添加均写入既有知识库标签；沿用每篇最多 3 个、每个最多 16 字的约束。批量操作逐项返回成功和失败。 |
| 10 | 官方来源模板 | ICH 保留目录与定期检查；新增 FDA 官方 JSON、EMA 质量指南分类、CDE 近期通告及 PubMed E-utilities 的手动检索。模板展示实际覆盖范围，不把仅元数据结果当作已取得 PDF。 |
| 11 | 精细关注 | 按来源、指南编号、关键词和变化事件类型关注既有变化事件；本人站内聚合摘要可暂停、筛选和标记处理。新模板不额外开启定时采集。 |
| 12 | 正文差异 | 比较实际已保存版本的提取正文，展示增删改及前后行号；缺少正文和截断范围明确提示，行号不当作 PDF 页码。 |
| 13 | 引用影响 | 展示本人可访问且含明确链接/版本标识的笔记、报告，提示旧版和未知版本引用；不以相似标题推断引用，不静默替换历史引用。 |
| 14 | 重复候选 | 依据 DOI、原件/正文摘要或相似标题给出候选，标明同文档不同版本；可核对并统一加入分类，原件、笔记和引用保留。 |
| 15 | 引用与原件导出 | BibTeX、RIS、CSV 和原件 ZIP；包含来源、版本和缺失清单，原件按 SHA 去重，导出前重新验权。单批最多 100 篇，PM 混合资料包上限 100 MiB，知识库共享原件子包沿用 64 MiB 上限。 |
| 16 | 按需加载 | 首页读取目录和统计，论文列表通过服务端查询每页最多 50 篇；正文仅按选中项和段落加载。复杂个人条件及原件/知识库混合排序在服务端读取必要元数据后再分页，不把全部正文下发浏览器。本版采用分页，不宣称已经实现无限虚拟滚动。 |
| 17 | 返回现场 | 同浏览器保留查询、排序、页码与选中文献；本人服务器记录目录、查询、阅读资料和滚动。跨页深链先重新验权再独立读取，知识库回链只接受受信门户路径。 |
| 18 | 文件夹问答 | 在指定目录已索引正文中召回相关片段，给出覆盖率和证据位置；无匹配不调用模型。显式选篇最多 20 篇，不把整个文件夹前 20 篇冒充全部依据。 |
| 19 | 多篇对比 | 用户选篇并主动发起，返回带有效证据编号的对比结果；每条证据保留原文入口、正文摘要和字符范围，结果注明使用节选。 |
| 20 | 分类建议与导读 | 复用本人工作台模型或系统默认模型，按需生成导读和现有目录分类建议；用户确认后才增加分类。按身份、版本、问题和模型设置缓存，重新生成明确再次调用。 |


## 入口与权限

正式入口仍为 `/knowledge-sources`，使用门户会话与 `/api/v1/knowledge-sources/v3`；知识库签名桥接配对部署后才具备完整能力。界面预览不连接真实文献、IAM、Core 或模型。

| 操作 | 实时权限与行为 |
|---|---|
| 共享文献检索、正文、原件与导出 | 知识库 `kb_viewer`、`kb_editor` 或 `kb_manager`，每次由知识库再验权；平台 `admin` 本身不获得全库阅读权限。 |
| 文件夹分类、规则归档与分类建议应用 | 知识库负责人权限及目录修订号；不把编辑权限扩大为目录管理权限。 |
| 共享标签和元数据更正 | 知识库编辑或负责人权限及相应修订号；标签沿用既有数量/长度限制。 |
| 来源设置与公开文件下载 | 沿用原来源管理权限及知识库写入校验；ICH 的既有委托不扩展为任意上传、删除或模型管理权限。 |
| 手动 PDF 上传及其问答索引 | 仅有效 `kb_manager`；普通平台管理员和编辑者不能据此发起 Core 全库增量索引。 |
| 集合、阅读、关注和返回位置 | 按本人已验证身份保存；不修改其他人的个人状态。 |
| AI 提问、对比、导读和分类建议 | 重新核对正文阅读权限和本人可用模型；不自动执行模型建议或替换报告引用。 |

### 手动 PDF 的索引确认

上传只保存原件及实际可提取的正文，不自动提交 ingest。Core 已确认收录但尚未激活注册的资料继续通过真实签名回执和受保护归档展示，不能把该回执当成可问答证明。

资料详情的“手动原件问答索引”需要勾选“处理知识库全部待索引资料”，再确认提交。当前 Core 的接口是**知识库级增量索引**，可能同时处理其他待索引资料并产生既有嵌入配置的费用。PM 创建持久化 `manual-index` 任务，仅调用绑定原始上传凭证的 `indexUploadedPaper/statusUploadedPaper`；关闭页面后继续跟踪，不重下或重导原件。

相同原件的活跃任务复用真实 taskId；权限失效会暂停跟踪，删除屏障或失败不恢复旧资料。未知结果、单纯“任务已提交”、完成但未活跃注册都不标 ready。通用下载的暂停、取消、继续和重试入口对该类任务返回 409，防止把停止 PM 跟踪误认为已停止 Core 任务；须回资料详情核对并明确确认。

## 本版范围

- ICH 继续使用既有目录、Q/S/E/M 和显式日/周计划。新模板都是手动检索：FDA 官方公开 JSON；EMA 按关键词优先读取最多 4 个质量分类；CDE 首页当前指导原则通告；PubMed 为 NCBI 元数据检索。任意新增网址仍不变成通用整站爬虫，也不默认获取全文。
- DOI/PMID 或普通 HTTPS 链接每次最多 10 项；官方搜索每次最多返回 30 项，结果凭本人一小时搜索回执选择收录。普通链接保留真实入口，DOI/PMID 从官方接口补元数据；受限或缺失 PDF 不以网页冒充原文。
- PDF 上传每批最多 10 份、每份最多 25 MiB；正文提取失败保留原件和失败提示，未加入 OCR。未注册资料的共享标签与元数据编辑须等知识库注册。
- 正文版本比较基于已提取文本，当前最多比较每版前 40 万字符、4,000 行及 300 个变化块，并提示截断；不是原始 PDF 像素差异。引用影响只识别本人明确资料链接/版本标识。
- 重复候选用于人工核对、统一分类，不自动合并或删除论文、笔记和引用。规则默认关闭，启用后仅作用于新收录批次；历史资料须预览后主动执行。
- 文件夹问答使用当前可检索正文的词法召回和节选，显示索引覆盖与缺口；不把缓存尚未覆盖的资料当作不存在，也不声称具备全文语义搜索。每次显式选篇最多 20 篇，研究请求每人每小时最多 20 次；缓存有效期 24 小时，仍重查权限、正文和模型设置。

## 数据与资源

- 手动 PDF 与来源原件使用既有内容寻址归档。Core 已提交但尚未注册时，需要真实签名收录回执才能展示、分类或阅读；注册后目录关系继续保留。删除屏障不能通过旧原件、旧回执或阅读进度绕过。
- 共享标签和元数据沿用知识库修订号；个人集合、阅读和位置记录按已验证身份隔离。分类撤销限本人、未过期且无后续冲突的凭证。
- 本地全文缓存可重建，并持续显示覆盖率；首次索引不完整时不声称全库无结果。缓存数据库与持久分类、收录回执、笔记和模型配置在部署核对中分别处理。
- AI 使用真实模型回执统计请求、已确认响应和 Token。没有费用账单时保持未计量，不显示为零费用。缓存命中不计新的调用；超时或失败可能仍产生上游费用，不将“无用量回执”解释为零调用/零费用；发生撤权或正文变化时，不返回旧缓存或迟到模型结果。
- 新规则和新采集计划不因发布自动启用。测试使用隔离的 IAM、Core、官网和模型响应；真实付费模型与客户业务操作验收单独记录。

## 验证入口

前端：知识源工作区、来源收录、手动索引确认、智能集合、阅读、批量整理与既有应用回归。后端：分页与过滤、共享修订冲突、签名回执、原件摘要、删除屏障、权限撤销、批量部分失败、规则幂等、手动索引 taskId/活跃注册及模型回执。知识库契约与浏览器检查维护在独立仓库的 `docs/knowledge-source-library.md`。通过数量、最终提交与镜像由执行回执提供，本文不替代发布证明。
