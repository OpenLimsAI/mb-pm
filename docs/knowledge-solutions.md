# 研究报告应用

本轮新增自动回答与公开搜索的开发预览：默认 Auto，通用问题直接回答、知识库问题查授权证据、近期信息进入公开检索；已选文献范围优先。搜索服务待管理员配置，本地演示逐轮标明「界面演示 · 未实际联网」。联网回答保留来源快照，插入报告继续验证引用。新增迁移 `014`，本轮未部署或进行真实联网验收，详见[自动问答与联网搜索](assistant-auto-search.md)。下文旧版先检索再生成的说明适用于知识库路径。
研究工作现场按已验证的身份空间、账号和报告保存在当前标签页的短期缓存，2 小时有效，每身份最多 5 份报告、单条最多 240k 字符。重新认证或刷新后先重新读取报告并核对作者、草稿状态及编辑权限，再恢复当前报告、章节、AI 问题、上下文、主题草稿及未完成卡片。资料范围逐项重新鉴权，核验未完成或失效时阻止生成，须重新选择或明确清除原范围；不会自动扩大资料范围。

恢复不自动重发付费模型请求，答案和可采纳引用只读取服务器历史。正文继续使用原有草稿备份，正式缓存键增加身份空间，未绑定旧缓存不自动导入。缓存不包含 OAuth 令牌、模型密钥或可授权的身份；换账号不恢复其他账号的内容。当前页面已验证身份遇网络或 IAM 暂时故障时保持挂载并显示重试提示，服务端仍逐次鉴权。

知识报告在门户 `/solutions` 独立挂载，沿用系统的深蓝顶栏、浅灰工作区、白色内容卡片和蓝色操作按钮。「排列布局」和高亮的「应用工作台」位于最顶栏，返回链接正式模式为 `/`、预览为 `/?preview=1`。整体报告名称、保存状态和信息入口并入「撰写报告」模块标题行，取消独立摘要行，为正文留出空间；窄模块按需换行，保留可操作的按钮。

首次打开采用分栏模式；「专注模式」开关放在撰写报告模块内，分栏时位于模块标题栏，专注时位于模块工具栏。开启后正文占满其余可用宽高，右侧窄工具栏保留目录、知识库、AI、引用和信息入口，需要时打开覆盖式辅助面板，一次只展开一项。

关闭模块内的「专注模式」开关，恢复之前的模块排列、可见状态及目录宽度。显示模式偏好保存在当前浏览器，不更改报告业务数据，也不因切换模式触发报告保存。切换时保留知识库已打开资料、问答输入、正文内临时卡片、正文撤销记录。本轮标题区域、返回链接与开关位置调整已完成本地预览验证，未推送或部署。

正文使用常驻格式工具栏，支持标题、加粗、斜体、项目列表和引用段落；Ctrl / ⌘ B、I 分别加粗和斜体，Ctrl / ⌘ Z 撤销，Ctrl / ⌘ Shift Z 或 Ctrl Y 重做。操作后恢复原编辑位置及选区；输入 `/` 仍可插入临时 AI 问答。列表中回车继续下一项，空列表项回车退出，中文组合输入期间不截获回车。输入框随正文增长，共用正文滚动区域，光标在长文中保持可见；工具栏随滚动保持可用。正文文字修改保留最多 100 步撤销记录，外部插入或卡片增删开始新的撤销边界；此记录仅在当前章节编辑期间保留，既有「撤销插入」仍由报告主流程处理。

### 选中文字问答与润色

在正文中用鼠标或键盘选择一段文字后，浮动菜单提供「询问 AI」和「Polish 文字」。Tab 可从已选择的正文进入菜单，Esc、点击其他区域或滚动可收起；只读报告不提供修改入口。

- **询问 AI**：在窗口输入问题，原文自动作为写作上下文附带，沿用当前回答模型、所选授权资料与项目范围。结果先展示，正式客户端沿用私有问答历史；「插入报告…」继续进入既有采纳确认，保留来源，不直接替换原文。
- **Polish 文字**：可填写语气、简洁度等要求，生成后对照原文，继续修改建议，再点「替换选中文字」。仅替换所选位置；保留选区前后的段落空白；数字和引用由用户核对，Ctrl / ⌘ Z 或正文撤销按钮可撤销本次替换。若等待期间原文发生变化，则拒绝覆盖并提示重新选择。关闭或处理失败均保留原文。

每次最多选择 5,000 字；润色要求最多 1,000 字，问答问题最多 4,000 字。分栏和专注布局均可使用，支持问答卡片前后的正文片段。润色需要可生成的共享模型或组织默认模型，不能使用「仅检索资料」，也不因知识库无结果而返回伪造的润色答案。生成期间锁定模型切换，关闭窗口或切换章节后迟到的结果不会修改正文。

开发预览只做明确标注的本机空格和标点整理，提供可编辑的结果来验证替换及撤销，不调用任何外部模型；预览问答继续检索演示资料。正式润色只向所选模型发送选中文字和润色要求，不发送全文、知识库原文或配方表；返回建议不自动保存报告、增加引用或进入问答历史。本轮仅本地预览，尚未推送或部署。

### 标题与报告公共数据

章节标题在撰写模式可直接点击输入，离开输入框或按 Enter 后提交，目录同步更新；最多 200 字，空白恢复原标题，Esc 取消当前修改。只读版本展示标题文本，章节目录的修改 / 删除菜单仍可使用；正文不再放置重复的铅笔按钮。

候选配方表原是整份报告共用的数据；本轮先移除每章下方的编辑表、目录中的配方计数和专注工具栏的配方入口。已有配方数据、引用绑定、历史和导出保留，不进行删除或迁移。引用和章节删除仍清理失效绑定。

### 模块布局与目录

分栏模式包含「撰写报告」「知识库资料」「AI 研究助手」三个模块。点击全局顶栏「排列布局」，上栏选择带 1、2、3 编号的排列图，下栏按顺序选择模块填入编号位置；选齐三个后点击「应用排列」。可点击已选模块取消并重新编号，或「重置顺序」后重新选择；取消不会改变当前布局。

| 排列方式 | 1 号位置 | 2 号位置 | 3 号位置 |
| --- | --- | --- | --- |
| 横向三个 | 左 | 中 | 右 |
| 左一右二 | 左整列 | 右上 | 右下 |
| 左二右一 | 左上 | 左下 | 右整列 |
| 上二下一 | 左上 | 右上 | 下整行 |

分栏中的三个模块分别可以隐藏；顶部保留对应的展开入口，其余模块使用腾出的空间，全部隐藏也能恢复。应用新排列时会展开三个模块。排列和隐藏偏好仅保存在当前浏览器，不写入报告正文或触发报告保存。分栏在窄屏按所选的 1、2、3 顺序纵向展示，保证每个模块可操作；回到宽屏会恢复选定排列。

本轮模块间尺寸调整已通过本地验证。桌面四种排列可拖动相邻模块间的分隔线，重新分配左右宽度或上下高度；窄屏改为纵向堆叠后，也可拖动分隔线调整上下模块高度。可用键盘聚焦分隔线并调整，双击分隔线恢复对应默认尺寸。首次打开使用默认比例或高度，后续尺寸作为本机显示偏好独立保存，不写入报告业务数据，也不触发自动保存。

调节尺寸不重新挂载知识库 iframe 或编辑器，保留已打开资料、输入问题、正文草稿和行内卡片。进入专注模式时保留原分栏尺寸，返回后继续使用。布局入口统一位于最顶栏，配置模型仅使用研究助手内高亮的「AI模型设置」按钮，移除布局旁及专注工具栏的重复配置入口。本轮本地验证通过，尚未推送或部署。

专注模式从右侧「目录」入口按需打开章节列表；分栏的报告撰写标题栏保留明确的目录隐藏和展开入口，隐藏后仍可恢复。目录与正文之间的分隔线支持拖动调宽，也可聚焦后按左右方向键，Home / End 跳到最窄 / 最宽。偏好宽度为 160–360 像素，窄模块中会限制目录占比为正文留出空间；隐藏、恢复及重排保留章节、正文和配方展开状态。目录宽度与显示偏好随浏览器保存。

产品依据为 2026 年 10 月 23 日《MBERP 知识方案应用业务需求文档》v0.1，及后续章节与布局反馈。

当前应用显示名称为「研究报告」，路由仍为 `/solutions`，既有报告和预览存储不变。顶部「研究报告主页」以工作台按钮样式返回本应用列表；当前修改保存失败时保留正文并提示处理。共享模型也可从工作台「功能设置 → AI 设置」进入 `/model-settings`，与助手内的配置共用同一组织配置。下方旧版验证记录中的「知识报告」保留历史名称。

## 对话主题与撰写空间

- 「新建对话」开始独立研究主题；主题选择器切换历史，首个问题作为标题，显示问答轮数。每个主题只显示自己的问答，同主题可持续追问。已完成问答会持久保存；旧版没有主题标识的问答以原回答标识各自形成主题，不删除或重写旧内容。
- 在当前报告内切换主题会保留未发送的问题和附带上下文；同一标签页的 2 小时恢复窗口内，刷新或重新认证后可在重新鉴权通过后恢复问题与上下文，已完成问答从服务器历史读取。关闭标签页、缓存过期或清除浏览器存储后不保证未发送草稿恢复。生成中可查看其他主题，返回的回答仍归原主题，其他主题的草稿不会被清空；同一时间的助手发送仍串行。
- 正式服务仅使用同作者、同报告、同主题的最近六个问题辅助理解；旧回答不会作为新证据，来源仍从当前授权与所选资料范围重新检索、验证。主题标识不扩大报告、资料或问答访问权限。正文卡片和选中文字问答分别形成独立主题。
- 每条回答有高亮「插入报告」，点击后确认或改写正文、选择章节并保留来源记录，确认后才写入报告，支持撤销。
- 正文去掉最大纸张宽度限制，缩小外边距，最后一个输入段落填满剩余编辑空间，并随长文自动增高；参考依据默认折叠，点击可展开，专注模式的依据面板仍可使用。保存状态和专注模式控件各自保留宽度与间距，窄栏隐藏状态文字但保留图标、提示和可访问名称。

服务端新增迁移 `008`，为 `solution_answers` 增加可空 `conversation_id` 与报告/主题联合索引；正式部署须先迁移，再启动新服务。本轮只在隔离测试库验证，未迁移或部署生产；本机预览仍使用演示资料检索，不调用真实模型。

## 文档导入

顶栏「导入」位于「导出」左侧，「排列布局」紧邻「应用工作台」左侧。选择单个 Word（`.docx`）、PDF（`.pdf`）或 UTF-8 Markdown（`.md` / `.markdown`）后，显示文件名、字数、报告名称和正文预览；确认「导入为新报告」后才保存。

- 浏览器本地解析，文件原件不上传至解析服务，不调用 AI；正式模式确认后通过既有报告接口保存提取的正文，开发预览保存在本机浏览器。
- 导入前先保存当前报告；保存失败或版本冲突时保留当前正文与导入预览。创建失败可重试，取消不改原报告。当前报告始终保留，导入成功打开独立的新草稿。
- Word/PDF 只提取正文文字，不保留图片、原版式或复杂表格；旧版 `.doc` 需另存为 `.docx`。PDF 需要文字层；扫描件需先 OCR，损坏或受密码保护的文件给出错误，不生成空报告。
- 单文件最多 20 MB、PDF 最多 500 页，解压后 Word 内容最多 32 MB；正文最多 200,000 字符。每章上限 50,000 字符，长文按段落自动分成续章，不截断正文。导入的内容不自动成为知识库证据或引用。
- 文档解析器按需加载，PDF worker、中文映射及标准字体随应用构建；不使用外部 CDN。只展示提取的文本，不渲染文档内嵌 HTML。

## 使用流程

1. 从工作台进入「知识报告」，新建报告或打开已有报告。填写项目、产品及章节；复制已有报告会创建新记录。
2. 在正文区域编辑章节，需要时从右侧「配方」入口打开候选配方表，保留物料、用量、单位、计量基准和选择理由。保存状态区显示正在保存、已保存或失败；发生版本冲突时先保留草稿，再重新载入比较。
3. 「知识库资料」默认展示原知识库的资料视图：搜索、文件夹、标签、上传、正文阅读与笔记沿用原功能及权限，去掉重复的问答和 AI 设置入口。窄栏可在资料库与阅读之间切换。选中文献后可「加入问答范围」或「引用到章节」。当前界面仅保留该知识库资料视图，「报告资料」页签及手动资料管理入口已移除。
4. 在研究助手「AI模型设置」添加组织共享模型，或在研究助手选择「组织默认模型」「仅检索资料」。输入问题，选择资料范围和可见的写作上下文；普通问答与正文 `/` 卡片使用相同的当前模型。知识库问答仅检索所选授权资料；新增 Auto 按问题选择通用、知识库或联网方式，显式所选资料仍限制为知识库。点击依据查看原文后，预览并手动插入章节。知识库模式没有配置企业默认模型时提供真实检索摘录，共享模型配置不完整或调用失败则明确报错。
5. 草稿继续自动保存并可导出 Word；当前界面已移除「提交评审」入口。既有评审中记录仍可继续处理或撤回，既有定稿、修订、历史与发布数据保留。此项仅本地预览，未部署。

### 正文内问答（本地预览已验证）

在可编辑章节正文中输入 `/`，从菜单选择「AI 问答」，即可在编辑器内打开临时问答卡片。卡片复用现有问答服务及资料范围，提问时可以附带写作上下文；上下文用于理解与检索，不作为文献证据。回答出现后先核对内容与来源，再明确确认采纳，正文与对应引用才一起写入报告。

未采纳的卡片及回答不属于报告正文，不进入报告保存、版本快照、定稿、Word 导出或知识发布。卡片位置只保留在本次打开报告期间，不承诺刷新或重新打开后恢复原位置；已完成回答仍可从现有问答历史查看。正式模式的历史按作者隔离并核验来源权限，演示模式仅保存在隔离的本地预览空间。本轮行内问答与目录入口调整已完成本地预览验证，尚未推送或部署。

章节目录支持添加、修改名称和删除，窄屏也保留操作入口。修改名称只更新该章节标题，不改变正文与引用；名称去首尾空白后不能为空，最多 200 字。删除前显示确认，至少保留一个章节。删除章节会同时移除其引用和配方中的相关依据绑定，受影响配方项回到待验证；其他章节及历史问答保留。可撤销最近一次章节删除，恢复章节与引用而不覆盖其他章节后续编辑。以上编辑操作仅对可编辑草稿开放，沿用自动保存与版本冲突保护。

## 数据与权限

生产模式经 `/api/v1/solutions` 保存到应用数据库，不依赖浏览器草稿作为正式记录。报告以已验证的 IAM 发行方及用户隔离，写请求检查门户 Origin；自动保存使用修订号，过期提交返回冲突，不能静默覆盖。评审与快照对应确切版本，问答历史默认作者私有。

首版以个人报告和指定评审为边界。项目名称为报告标签，不代表继承 PM 项目成员权限；报告应用不提供任意团队共享、多人实时合编或生产配方下发；附件上传与解析在原知识库中按其功能及权限执行。内部定稿不替代企业生产及质量流程。原始 BRD 中的项目自动关联、完整附件管理及更复杂协作需要继续建设。

「报告资料」功能暂时下线：移除单独的资料列表、搜索筛选、手动添加资料和发布定稿到个人资料集合的界面入口，不再自动请求旧资料列表。资料浏览与上传统一使用嵌入的知识库；选择原知识库文献后仍可加入 AI 问答范围或引用到章节。

服务端已有个人资料、报告、问答和引用继续保留。历史引用与回答来源仍可按原权限查看，暂不删除旧表或兼容接口，后续需要时再设计独立资料管理功能。

## 修改报告名称

在报告列表中，作者可选择草稿卡片上的「修改名称」，输入新名称并保存。系统先核对最新修订，避免覆盖其他页面修改；正文、引用和历史版本保留。评审中或已定稿的报告需先返回草稿或创建修订，其他作者的报告不可修改。

## 报告删除与恢复

报告列表中，作者可在报告卡片选择删除并确认，将报告移入回收站。报告正文、版本、引用和问答历史保留，指定评审者在删除期间不能访问；作者可从列表的「回收站」恢复报告。已发布为独立资料的内容不会随报告删除。操作按作者和身份发行方隔离，并使用修订号避免覆盖其他页面的修改。知识库权限被撤销时，包含受限依据的报告仍遵循原有资料访问限制。

## 企业知识库连接

资料视图通过固定知识库入口的 `?embed=library&parentOrigin=...` 嵌入，等待专用视图的 ready 消息后才显示；工具栏保留刷新，移除新窗口打开入口。旧版知识库、网络或登录未完成时提供重新加载与状态提示，不能只隐藏外层样式假装移除了 AI。必须配套知识库的 `library-embed` 版本；生产代理的 frame 策略与真实登录验收结果以发布记录为准。

门户 Cookie 不能充当独立 KB 应用会话。后端使用固定的 DIKW Core 连接，并在每次企业资料访问时向 IAM 实时确认 KB 角色。平台管理员身份不会自动取得知识库权限；入口目录缓存不用于资料授权。

研究报告的原知识库面板使用 KB 自己的会话。配套 KB 会明确报告「需要恢复登录」「没有访问权限」或「服务暂时不可用」，面板收到会话失效通知后隐藏原资料并清空旧选择。正常加载较慢时仍接受迟到的就绪通知，不把超时永久当作登录失败。

需要恢复时，点击「恢复知识库登录」会在独立窗口发起 KB 标准 OAuth，固定回到 `/web/auth/report-return`。已有 IAM 会话可继续单点登录；IAM 会话也失效时需要重新验证。报告正文保持打开，不因登录跳转打断尚未保存的编辑。登录完成通知必须同时匹配 KB 来源、该次打开的窗口及协议版本；浏览器隔离了窗口引用时，返回报告的焦点/可见性事件会重载面板，也可点击「重新加载」。弹窗被拦截会提示允许后重试，不改为自动离开报告。消息不能指定登录 URL、回跳地址或提升知识库权限。

此恢复协议已随 PM `e0b6f85`、KB `edec8fe` 配套发布，包括匿名嵌入响应、会话失效通知和固定登录终页；有效 IAM 会话可自动恢复。生产验证与版本见[发布记录](../deploy/parallel-test/releases/20261102-knowledge-sso.md)。旧版 KB 只会在超时后提供手动恢复入口。IAM 重建导致统一登录会话丢失的根因与生产验证单独见 [2026-11-02 调查](verification/2026-11-02-knowledge-sso.md)。本次真实浏览器已验证直接进入和刷新资料面板均无需再次登录；未对真实用户强制过期或退出账号。

原知识库的浏览与管理使用自己的 BFF 和权限，不依赖以下报告适配变量。将资料用于报告引用或 AI 问答仍需要这些连接配置；iframe 消息只传路径和标题，不传正文、令牌或可信引用，也不会把企业原文转存个人集合。

后端进程可配置以下环境变量，不得带 `VITE_` 前缀：

| 变量 | 作用 |
| --- | --- |
| `SOLUTION_KB_CORE_URL` | 固定的 Core 服务地址，不允许用户提交任意代理地址 |
| `SOLUTION_KB_TOKEN` | 服务端 Core Bearer 令牌，仅由运维注入 |
| `SOLUTION_KB_PUBLIC_URL` | 用户可打开的知识库页面地址，示例为 `https://kb.openlims.ai` |

参见后端示例配置。连接未配置时仍可撰写和使用手动资料，界面明确提示企业知识库尚未连接；不能据此声称已检索企业论文。外部检索错误与无结果分开返回。

问答使用下述组织共享模型，兼容历史模型引用，不复用 KB Agent 的会话或配置。用户选择资料的限制在后端执行，写作上下文可用于缩小检索问题，但不被当成文献证据。模型请求配置 60 秒连接 / 读取超时；DNS 使用系统解析器，不承诺所有阶段合计严格为 60 秒。前端对包含企业资料读取的整个问答请求最多等待 5 分钟，超时会保留问题并显示重试入口。

## 组织共享模型配置

点击研究助手内高亮的「AI模型设置」，添加、编辑和删除组织共享模型配置。支持 DeepSeek、MiniMax、Kimi、GLM、OpenAI、`custom` 自托管兼容服务和 Ollama；每个组织最多 20 组，同一服务商可配置不同模型及用途。每组填写配置名称、服务地址、模型 ID 和可选密钥，模型 ID 可从带参考价的预置列表选择，也可按本人服务商控制台手动填写；型号与账号开通范围仍需确认。

以下云服务与 OpenAI 兼容服务的基础地址由服务追加 `/chat/completions`，填写时不要重复该路径；支持兼容对话请求，不意味着支持供应商全部专用参数。Ollama 单独使用服务根地址与 `/api/chat`，不需要 API 密钥。

| 服务商 | 基础地址 | 官方参考 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | [Chat Completions 接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) |
| DeepSeek | `https://api.deepseek.com` | [对话接口示例](https://api-docs.deepseek.com/guides/multi_round_chat/) |
| Kimi | `https://api.moonshot.cn/v1` | [官方快速开始](https://platform.kimi.com/docs/get-api-key) |
| MiniMax | `https://api.minimax.io/v1` | [OpenAI-compatible 接口定义](https://platform.minimax.io/docs/api-reference/text/api/openapi-chat-openai.json) |
| GLM | `https://open.bigmodel.cn/api/paas/v4` | [OpenAI API 兼容说明](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction) |
| 自托管兼容服务 | 用户填写 HTTP(S) 基础地址 | 须提供兼容的 Chat Completions 接口，允许不带密钥 |
| Ollama | `http://127.0.0.1:11434` | 服务根地址；自托管来源仍须通过服务器批准 |

可将其中一组设为组织默认模型。研究助手「回答模型」可选择任一共享配置、组织默认模型或仅检索资料；普通问答、选中文字问答与润色、正文 `/` 卡片共享当前选择。失效、缺密钥或不可用的配置明确报错，不借用其他组织或个人密钥。知识库问答仍先检索当前用户有权读取的原文，使用模型后校验来源编号。保存共享配置不改动报告、个人任务或笔记。

正式模式按门户已验证的 `(issuer, organization)` 保存共享配置，密钥与配置由 `APP_SECRET` 加密后存于 `organization_ai_settings`。旧 `solution_ai_settings` 个人配置和密文保留，不自动公开；历史无前缀模型引用按原个人身份解析。新共享 ID 带 `shared:` 前缀。读取只显示密钥是否已设置，不回显；留空仅在服务商和规范化服务地址均未变时保留原密钥，显式清除会移除密钥，换服务商或地址不继承旧密钥。云服务可先保存无密钥配置，但提问和测试会要求补齐；`custom` 可用于无密钥自托管服务。多页面编辑使用独立修订号保护，过期保存返回 409，不覆盖另一页面的新设置。配置名称最多 80 字、地址 500 字、模型 ID 160 字、密钥 2000 字。

「测试连接」只在明确点击时发送固定短消息，不发送报告、资料或写作上下文，不自动保存草稿，结果仅包含是否成功、模型名称与耗时。自托管地址由后端访问，允许明确本机 / RFC1918 / ULA 网络；禁止云元数据、链路本地、特殊地址、URL 内凭据、查询和片段。连接不走代理或重定向，DNS 校验后固定 IP，HTTPS 仍校验证书和原主机名。详见[配置与权限](configuration.md#知识报告个人模型)。

接口均复用门户身份、同源写保护和临时密码守卫，不要求获得 PM 全局 AI 设置管理权：

| 接口 | 输入与输出 |
| --- | --- |
| `GET /api/v1/solutions/ai/settings` | `{profiles, default_profile_id, revision}`；返回当前组织共享目录；每组返回 `id/name/provider/base_url/model/key_set`（共享 ID 带 `shared:` 前缀） |
| `PUT /api/v1/solutions/ai/settings` | 整份 `profiles`、`default_profile_id`、`revision`；每组额外可传 `api_key`、`clear_key`，不传 `key_set`；成功返回新修订号，冲突返回 409 |
| `POST /api/v1/solutions/ai/test` | `{profile: 配置草稿}`；返回 `{ok: true, model, ms}`，失败只返回通用提示 |
| `POST /api/v1/solutions/{id}/ask` | 增加可选 `model_profile_id`：省略或 `null` 使用组织默认；`system` 是同一共享默认的兼容选择；`retrieval` 强制摘录；新目录 ID 为 `shared:...`，历史个人 ID 保留原身份校验 |
| `POST /api/v1/solutions/{id}/polish` | `{section_id, text, instruction?, model_profile_id?}`；仅作者草稿，返回 `{content, model, mode: "ai"}` 建议，原报告不变；文本最多 5,000 字，要求最多 1,000 字 |

无效或不属于本组织的共享配置 ID 返回 404，即使没有检索结果也不能绕过校验；缺少云模型密钥返回 422；验证失败不会回显含密钥的请求内容。开发预览只按隔离 namespace 保存非秘密配置元数据，不接受真实密钥、不测试连接、不调用模型。模型选择在预览中仅用于演示，回答仍明确标为演示资料检索。此组织共享变更仅在本地开发，未部署或完成真实模型验收。旧 MiniMax 导入及部署变量计划见[共享 AI 设置](shared-ai-settings.md)。
