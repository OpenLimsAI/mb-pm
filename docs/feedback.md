# 回音壁

在项目管理或知识库右上角点击“回音壁”，新标签页直接打开提交窗口。所属应用和来源页面自动填写；可以修改应用。页面查询参数及登录认证信息不进入来源链接。直接从工作台进入时手动选择应用。

## 提交与补充

选择 Bug 或新功能，填写描述，也可使用复现步骤、预期/实际结果或场景/收益模板。描述输入后会展示相似反馈；如果已有同样问题，可以点击“我也遇到了”并关注。图片支持上传、Ctrl/Cmd+V 粘贴，或点击“截图并标注”选择需要的窗口。截图编辑支持裁剪、箭头、方框、文字和不透明遮挡，确认后才加入附件。系统不会自动录屏或读取剪贴板。

每条反馈和每条回复最多 3 张图片，每张 5 MB。反馈详情支持继续附图回复；提交者或管理员可编辑原文及图片，历史记录保留修改前后内容。复制编号旁的链接可直接分享本组织内的详情；其他组织和未登录用户无法读取。

## 跟进与验收

成员可认领反馈，当前处理人或管理员可填写优先级和计划完成日，管理员可转派给其他启用账号。修复者提交修复说明及验证步骤后进入“待发布”；登记版本后进入“已上线·待验证”。提交人复测后点击“确认已解决”，如果仍有问题，填写原因点击“仍有问题”退回处理。修复完成并不表示代码已经部署，登记上线也不会执行服务器部署。

回复、分派和状态变化会产生系统内通知。点击通知可打开对应详情，读取后消除未读提示；关注开关控制是否接收后续更新。工作台集中显示待分配、未回复、逾期和待验证反馈，并提供按应用统计的真实响应及解决指标。没有可计算记录时显示空值，不虚构历史处理时间。

## 草稿与历史

提交窗口和每条反馈的回复分别保存草稿，刷新或重新登录后可选择恢复。草稿按后端提供的身份隔离，在当前浏览器保存 14 天。图片使用 IndexedDB；浏览器禁止存储或空间不足时会提示，图片无法保存时不声称已完整保存。成功提交或明确放弃会删除草稿。

旧反馈继续保留原状态，不补造处理人、修复时间和验收结论。删除自己的反馈或管理员确认删除会同时删除关联回复、图片和通知；删除前请核对内容。

## 发布维护

部署必须使用全部 CI 通过且已 squash 合并的固定主分支。新增列、表及历史短编号由独立 schema owner 执行，正常运行角色不授予 DDL。发布前加密备份并在隔离副本验证恢复，保留完整 Compose 顺序、镜像与源码校验、上线验证和回滚记录。回滚切换旧镜像，不删除新表或恢复旧数据库覆盖新内容。
