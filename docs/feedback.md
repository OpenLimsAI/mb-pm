# 回音壁

## 提交问题

从工作台打开回音壁，或点击项目管理、知识库右上角的“回音壁”。跨应用入口在新标签页打开并预选应用，原页面保留。

点击“提交反馈”，选择所属应用及 Bug / 新功能，填写问题描述后提交。图片选填，支持上传、Ctrl/Cmd+V 粘贴和主动截图标注；每条反馈或回复最多 3 张 PNG/JPEG/WebP，每张不超过 5 MB。复现步骤和相似反馈位于可选补充中，不影响直接提交。

## 回复与修复

反馈只有“待处理”和“已修复”两种状态。组织内任何已登录成员都可以：

1. 在列表卡片直接点“标记已修复”，也可进入“回复”详情后点击同名按钮。
2. 选填回复说明，或在发送回复时同步标记已修复。
3. 仍有问题时点击“重新打开”，回到待处理。

不再要求认领、分派、填写验证步骤、登记上线或由原提交人再次验收。修改状态会记录实际操作者和时间，普通回复不会自动覆盖别人刚更新的状态。通知和未读提示继续保留。

## 保留的数据与权限

原反馈、图片、回复、编号、关注和编辑记录保留。旧“处理中”按待处理展示，旧“待发布 / 已上线待验证”按已修复展示，原始数据库记录及历史时间线不批量改写，也不补造修复时间。过去填写的修复说明等信息可在详情查看。

草稿按身份和反馈编号隔离，14 天内可恢复；成功提交或明确放弃后清理。图片存储不可用时会提示。提交人及管理员的编辑、删除权限保持原规则；只有修改基本修复状态向组织成员开放，其他组织和未登录用户仍无法读取或修改反馈。

## 本地验证与交付

本地统一入口固定为 `http://localhost:1234`，沿用现有 `pm_ai_local_20261109` 数据库、模型配置和加密密钥。测试使用独立临时数据库。本轮简化不需要数据库结构迁移或清理历史数据。

代码交付遵循 PR、全部 CI 通过及 squash merge。生产发布另按固定合并提交、备份、验收和回滚流程执行；本地修改与测试通过不等于正式环境已部署。
