## 用户可见变化与原因

长周报下方的隐藏辅助标签采用绝对定位，而项目内容滚动区没有建立定位边界。标签借用了 body 的定位范围，长内容滚动后撑高外层文档，造成正文和侧栏已结束而下方仍有大块可滚动空白。真实 Chrome 因果复现中，982px 视口的文档高度达到 10357px；只补定位边界后降至 982px，撤销该规则后重新出现 10357px，主内容的正常滚动范围不变。

项目内容区现统一承担定位与内部滚动，外壳限制溢出，右栏允许收缩。身份刷新提示纳入同一高度预算，避免额外叠加整屏外壳。长短内容切换、窄窗口、甘特图及 WBS 全屏返回均在浏览器中回归；门户和其他独立应用没有采用全局禁止滚动。

回音壁同时上线已合并的简化功能：在列表或详情中提交、回复、标记已修复和重新打开。同组织普通成员可以直接更新修复状态；原图片、回复、编号、通知、草稿和编辑/删除权限保留。旧状态按待处理或已修复展示，不批量改写历史。
