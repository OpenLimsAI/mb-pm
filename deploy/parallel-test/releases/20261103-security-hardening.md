### 身份异常响应的准确语义

- 明确 inactive token，或完整有效证据中的 client/subject/organization 不匹配，返回401。
- 完整用户记录明确停用/删除，返回403；角色撤回不继续沿用登录时JWT中的旧权限。
- 超时、缺失/null/空白/类型错误身份字段返回503，当前受保护请求失败，会话保留供期限内重试。
- Casdoor软删除可能返回 `status:error,data:null`；此时仍是503失败关闭，不能笼统宣称所有删除都返回401/403。
- 刷新不改变原始认证时间，不能绕过改密撤销；已经开始的操作不保证被追溯中止。

生产组织实际字段规则：Roles为Public/Immutable；Is forbidden、Is deleted、Need update
password、Last change password time为Self/Admin。应用的“已验证”开关不能代替这五项元数据核对。
IAM持久化保留尚存SSO会话，不能恢复此前容器替换时已经丢失的登录；部分历史会话仍须重新登录一次。
