# 2026-11-19 知识源文件夹自动导入与资料整理

从知识源的目标文件夹打开「自动导入设置」，选择来源目录并设置扫描时间。发现资料后，系统会将其归入该文件夹，解析内容并建立问答索引。

在资料列表中，「拷贝到」保留原有分类，「移动到」可更换资料所在的文件夹。「移出此文件夹」只解除当前分类。要删除资料，可在「更多」中选择全库删除并确认。

搜索时可查看当前范围并逐项清除筛选。批量上传 PDF 时，每份文件分别显示处理结果。

相关变更见[门户功能 PR #233](https://github.com/OpenLimsAI/mb-pm/pull/233)、[知识库 PR #68](https://github.com/OpenDIKW/dikw-mbweb/pull/68) 和 [Core 依赖更新 PR #234](https://github.com/OpenLimsAI/mb-pm/pull/234)。
