2026-10-18门户与项目协作升级本次更新

01
AI 分析本次重大升级

把项目和财务数据整理成行动建议

新增项目分析与组合财务分析，支持默认提示词、本次关注重点、最近 20 份报告存档和 Markdown 导出。数据变化后提示报告过期，分析结果不直接修改业务数据。

在哪里项目详情 → AI 分析 · 财务 → AI 财务分析
谁能用管理者；组合财务分析限系统管理员 / CMC 负责人
02
账号与权限

每位成员都有自己的工作视图

在登录页直接输入迈博账号登录，按角色和项目关系展示数据。账号由系统管理员在门户「账号管理」开通，本系统不提供自助注册；已登录用户在门户工作台「我的设置」修改自己的用户名和密码。

在哪里登录页 · 门户工作台 → 我的设置 · 账号管理（系统管理员 / 项目负责人）
谁能用所有成员
03
任务协作

把今天该做的事集中到一处

新增我的看板和跨项目任务清单，可按负责人、状态、优先级及逾期情况筛选。管理者可批量调整状态和负责人，执行人员可更新自己的任务。

在哪里首页 → 我的看板 · 项目 → 任务
谁能用所有成员，操作范围按角色区分
04
计划与资源

提前看见排期冲突和人员过载

联合甘特图汇总多项目时间轴；人员负荷支持 4 / 8 / 12 周热力图和未来 4 周过载预警。推荐负责人结合专业组与负荷，支持对指定任务改派。

在哪里项目 → 甘特图 / 人员负荷
谁能用管理者；执行人员使用单项目甘特视图
05
风险推演

先看延迟影响，再决定如何调整

选定任务与延迟天数，沿依赖链推算受影响任务、关键路径、里程碑和项目完工时间。推演结果供决策参考，不会自动修改原计划。

在哪里项目详情 → 延迟推演
谁能用可访问该项目的成员
06
预算管理

让任务花费与项目预算使用同一口径

项目已花费由任务实际花费自动汇总；系统管理员和项目负责人可维护项目预算、已承诺金额及成本结构，修改保留审计记录。

在哪里项目详情 → 编辑项目 → 预算与成本 · 财务
谁能用预算编辑限系统管理员 / 项目负责人（旧角色限本人负责或参与的项目）
07
项目结构

已建项目也能像模板一样调整结构

编辑项目与模板结构编辑同一用法：增删改子项目、任务、里程碑和依赖后一次性保存，多人同时编辑时提示重新载入，已开始的任务受删除保护；任务可插在任意两个任务之间并拖动排序。复制项目可把已有项目作为蓝本开新项目，执行数据自动重置。

在哪里项目详情 → 编辑项目 · 项目列表 → 复制项目

GET STARTED

从适合你的入口开始

系统管理员 / CMC 负责人

  1. 首页查看组合总览，进入财务维护项目预算。
  2. 在项目管理「AI设置」中配置模型，按需生成项目或财务报告。
  3. 系统管理员在门户「账号管理」中开通账号、设置身份；项目负责人可在那里查看成员名单。
  4. 开新项目时可用项目列表的「复制项目」，以已有项目为蓝本。

项目负责人

  1. 在自己负责或参与的项目中安排任务、维护任务预算；需要增删任务、子项目或修改预算时点项目页首的「编辑项目」。
  2. 使用任务筛选、联合甘特和人员负荷检查排期。
  3. 结合延迟推演和项目 AI 分析评估调整方案。

工艺开发 / 生产支持 / QA/QC

  1. 从首页我的看板查看个人待办，点击任务录入进展。
  2. 在项目 → 任务中筛选并更新自己的任务。
  3. 实际花费目前在项目详情 → WBS → 表格录入的花费列填写。

使用前，了解这些边界

  • 账号开通：已有业务成员并不等于已开通 IAM 登录。账号与业务成员需正确关联，角色和项目范围由管理员分配。
  • AI 使用：管理员须先配置模型服务。生成分析会将相应项目或财务数据发送给所选服务；请在界面确认数据范围后使用。分析仅作参考。
  • 财务口径：金额单位为万元，实际花费来自任务录入，不含内部人力；尚未对接公司财务系统。成本结构由人工维护。
  • 删除项目：会连同子项目、任务、依赖、团队关联、财务与基线记录删除，无法在界面撤销。操作前请确认项目编号。
  • 编辑项目与复制项目：需连接后端使用，离线演示模式不可用。修改日期不会自动顺延后续任务，请按冲突提示自行调整。
  • 功能边界：任务抽屉和我的看板暂未提供实际花费录入；偏差 / CAPA / 批次系统集成尚未完成，不属于本次已交付功能。

改进

  • 项目详情页首、项目卡片与表格的计划起止改为按任务实时计算（最早开始 → 最晚结束），任务调整后立即反映；基线对照、复制项目与 AI 分析使用同一起止。
2026-10-14任务插入与手动排序任务可以插在任意两个任务之间，也能拖动调整顺序+

项目编辑模式和模板结构编辑都支持在两个任务之间插入、拖动排序；WBS 树形、表格录入和甘特图按同一手动顺序显示。无需配置。

新增

  • 鼠标移到任务行上，行上沿出现「＋」，可在任意两个任务之间插入任务或里程碑；不预设前置依赖，项目中开始日期默认接在上一个任务之后，可在表单中修改。
  • 拖动任务行左侧的手柄调整顺序，也可以拖到其他子项目；选中手柄后可用 ↑ ↓ 键移动。

改进

  • WBS 树形、表格录入、甘特图与编辑模式使用同一手动顺序；原有任务按升级前的显示顺序（计划开始、编号）保持不变，用模板创建的项目沿用模板中的先后。
  • 编辑和新建任务时，「前置依赖」默认展开。
2026-10-13项目编辑模式与复制项目已建项目可以像编辑模板一样增删任务，也能复制成新项目+

项目详情新增编辑模式，与模板结构编辑同一用法；项目列表新增复制项目。两项都需连接后端使用，无需额外配置。

新增

  • 编辑模式：在项目概览的三级 WBS 卡片或 WBS 页签右上角进入，增删改子项目、任务 / 里程碑和前置依赖，改完一次性保存；限系统管理员、CMC 负责人和该项目的项目负责人。
  • 编辑期间如有他人修改了项目结构，保存时提示重新载入，避免互相覆盖；日常录入进度不受影响。
  • 已开始或已录实际花费的任务不能删除；修改日期不会自动顺延后续任务，与前置任务冲突时行内提示，并可一键改到前置结束之后。
  • 复制项目：在项目列表右上角选择已有项目，填写新编号、名称、负责人和计划开始，生成结构与计划相同的新项目；限系统管理员 / CMC 负责人。
  • 复制时任务全部重置为未开始，不带实际日期、工时和花费；已承诺金额与成本结构清零，不复制基线和 AI 报告；修改计划开始时全部计划日期整体平移。

改进
