AI 分析本次重大升级

04
计划与资源

提前看见排期冲突和人员过载

联合甘特图汇总多项目时间轴；人员负荷支持 4 / 8 / 12 周热力图和未来 4 周过载预警。推荐负责人结合专业组与负荷，支持对指定任务改派。

GET STARTED

从适合你的入口开始

系统管理员 / CMC 负责人

  1. 首页查看组合总览，进入财务维护项目预算。
  2. 在设置 → AI 分析中配置模型，按需生成项目或财务报告。
  3. 系统管理员在组织中管理业务成员；IAM 管理员分配对应账号角色。

项目负责人

  1. 在自己负责或参与的项目中安排任务、维护任务预算。
  2. 使用任务筛选、联合甘特和人员负荷检查排期。
  3. 结合延迟推演和项目 AI 分析评估调整方案。

工艺开发 / 生产支持 / QA/QC

  1. 从首页我的看板查看个人待办，点击任务录入进展。
  2. 在项目 → 任务中筛选并更新自己的任务。
  3. 实际花费目前在项目详情 → WBS → 表格录入的花费列填写。

使用前，了解这些边界

  • 账号开通：已有业务成员并不等于已开通 IAM 登录。账号与业务成员需正确关联，角色和项目范围由管理员分配。
  • AI 使用：管理员须先配置模型服务。生成分析会将相应项目或财务数据发送给所选服务；请在界面确认数据范围后使用。分析仅作参考。
  • 财务口径：金额单位为万元，实际花费来自任务录入，不含内部人力；尚未对接公司财务系统。成本结构由人工维护。
  • 删除项目：会连同子项目、任务、依赖、团队关联、财务与基线记录删除，无法在界面撤销。操作前请确认项目编号。
  • 功能边界：任务抽屉和我的看板暂未提供实际花费录入；偏差 / CAPA / 批次系统集成尚未完成，不属于本次已交付功能。

RELEASE NOTES

每一次变化，都有记录

按时间倒序 · 展开查看详情

以下名称用于区分功能阶段。历史日期依据代码提交记录整理，不等同于客户环境的上线日期。

2026-10-01账号开通调整账号统一在 IAM 平台开通本次更新+

移除本系统的自助注册入口，已有账号继续使用 IAM 登录。

调整

  • 登录页不再显示“还没有账号？注册新账号”，改为“所有用户信息在iam平台管理”。
  • 旧注册链接返回登录页，本系统不再受理自助注册请求。
  • 新账号请由管理员在 IAM 平台开通，并关联项目管理成员及角色。
2026-10-01交互体验修正让编辑草稿与数据刷新衔接更顺畅+

优化任务、模板、人员列表与甘特图的数据同步，减少页面切换和刷新时的信息错位。

修正

  • 切换任务时同步进展表单；无关数据刷新时保留正在编辑的内容，任务字段变化时显示最新值。
  • 切换模板时建立对应草稿，同一模板刷新时保留未保存的编辑。
  • WBS 子项目、负责人选项和组织成员列表随数据变化及时刷新。
  • 更新排期或缩放甘特图后，选中任务的定位使用最新时间轴。
2026-09-28界面焕新深蓝导航与清爽的卡片工作区+

统一系统首页、导航和版本更新页的视觉语言，让项目数据和操作入口更清晰。

视觉

  • 采用深蓝顶栏、浅灰工作区、白色卡片和青蓝操作色，绿色标识当前导航与内容标题。
  • 左上角使用迈博药业企业标识，顶部统一为指定的深蓝色 RGB（35, 72, 111）。
  • 项目组合指标统一使用白底、深色数字与灰色说明，取消彩色底栏；风险与预算状态继续按实际数据展示。
  • 版本更新页重新设计功能卡片、对照表和更新记录；AI 分析保持首位与“本次重大升级”标签。

体验

  • 窄屏使用图标导航，功能说明卡片自动切换为单列。
  • 增加键盘焦点提示，并保留 HTML 下载、打印和历史记录展开功能。
2026-09-28功能说明更新新增版本更新中心+

把每次升级的变化留在系统里，方便新成员上手，也便于老用户回看。

新增

  • 左侧导航新增版本更新入口。
  • AI 分析置于功能介绍首位，以“本次重大升级”标签重点展示。
  • 提供新版亮点、旧新功能对照、角色上手指引及功能边界说明。
  • 支持独立 HTML 阅读、下载和打印；历史更新按时间倒序保留。
2026-09-28IAM 协作版统一账号，贯通任务、资源、预算与分析+

在原有组合总览和项目管理基础上，增加面向不同角色的日常协作能力。

重大功能

  • 项目 / 财务 AI 分析、模型设置、提示词、报告存档及 Markdown 导出。

新增

  • 统一登录与退出、可配置的自助注册、用户名和密码自助修改。
  • 个人看板、跨项目任务筛选和批量操作、多项目联合甘特图。
  • 人员负荷热力图、过载预警、推荐负责人和任务改派。
  • 项目延迟推演、项目删除确认流程。

增强

  • 项目预算可编辑，预算变更记录修改人及前后值；任务实际花费自动汇总至项目。
  • 新建项目的总预算默认取任务预算合计，实际花费不再按进度预填演示数值。
  • 按登录身份约束任务操作及财务、基线数据范围；执行人员不能修改任务预算。
  • 任务、甘特图、人员负荷收在项目导航分组中，可折叠。
